# 运镜技法与提示词编译

用于已有场景、分镜或用户点名运镜的任务。先用[运镜决策](camera-movement-story-decisions.md)确定观看任务；需要比较术语时按需查[技法速查](camera-movement-vocabulary.md)。这些是导演目标和写法，不是相机控制插件、模型预设或新增 MCP 参数。纯提示词任务直接写，不要求启动制作服务。

## 从名称到可执行镜头

把一个运镜写成“**因何启动 → 从何处看 → 用什么机制沿哪条路径 → 怎样加减速 → 途中什么关系变化 → 落到何处并交给下一拍**”。名称只是检索简称；删除名称后，正文仍应说明相机和主体各自在做什么。

- **主体动作独立写**：人物跑向门，不等于相机也跑；相机后退跟拍，不等于人物倒着走。给出相对距离、朝向、先后和地标。
- **主运动先明确**：普通镜头选一个主运动；需要组合时说明同时还是先后，例如“先跟随至门口，人物停下后相机绕到侧面”。不要把摇摄、横移、环绕、变焦全当作加强语气的词。
- **方向有参照**：横移的左右以起始相机面向为准，人物左右另注明；环绕的顺/逆时针默认从场景上方俯视并写明，另给起点、绕行侧与终点，避免只用“向右转”。轨迹改变时，画面内运动方向未必相同。
- **速度写过程**：缓启动、匀速段、制动、停稳是可选的运动阶段；动作触发和证据可读时间决定时长，不固定套“慢速”。跟拍可持续运动到出镜点，不强行每镜停住；需剪辑匹配时保留退出方向与速度。
- **构图写关系**：说明前景遮挡、主体占比、背景视差和焦点谁变谁不变；相机锁定不代表人物、服饰、光线或环境冻结。转弯显露的新区域必须属于同一既定空间。
- **落点有内容**：停稳是为了看清手中的选择、门后的事实或群体关系。若只需要凝视和表演，固定镜头有效，不用空推镜填时长。

可在原分镜 F 中简记以下内容，无需建立另一套项目字段或让用户填表：

```text
观看任务/触发：……
主体：动作方向、速度、停点……
相机：起始构图与地标 → 位移/旋转/变焦/焦点机制 → 路径与速度 → 终态
读取：途中可见顺序、关键动作/表情在何种景别与焦点下被读到、最后阅读时间……
参考：单图/必要首尾帧/四状态；选择原因……
接续：下一镜继承的位置、视线、动作相位和运动方向……
```

这份简记要编译为自然语言实际 prompt；不能只把它放在计划里，提交时又剩下“cinematic tracking shot”。中文为现有默认，用户指定语言、逐字对白与目标模型结构保持。

## 把摄影与表演写在同一事件里

每个关键秒段交代“观众此刻看什么 → 相机在哪里/怎样响应 → 人物怎样变化 → 结果何时可读”。恒定构图只需写一次；后续发生景别、位置、焦点或主要观看对象变化时就地接续。不要先写一串细微表情，再另附一段与表演时间无关的“电影感运镜”。情绪影响摄影的距离、启停和停留，摄影也决定哪些表演细节有表达价值。

例如，对峙中的一次挥击与格挡，若主要证据是双方接触，可以先让双人中全景覆盖起势、攻击路径与接触，反击或后退发生后再接反应。下面是可选的局部写法，只示范衔接，不是完整生成稿或固定秒数配方：

> 挥击与格挡期间保持双人中全景，双方手中的器物与接触点均在画内，焦点覆盖这一动作平面；受击者重心后移但脚步未退，格挡结束后将器物收回胸前。攻击者看向对方仍站稳的脚，相机此时才沿朝向受击者的路径缓慢前移，固定焦段，从双人中全景过渡到他的中近景；攻击者随画框收窄退出画面，相机始终留在原来观察对峙轴线的这一侧。到达后受击者抬眼，刚才紧抿的嘴唇放松，回应对方。镜头在回话前已给脸部留出足够画面，才由这个细节表达镇定。

选用这一拍法，须按实际空间和时长给推进、反应与对白留出区间，并核实起始机位确实能沿该方向到达；不够就改拍法。若用户锁定固定双人全景，则保留同框，用站稳、收回器物、攻击者后撤半步表达控制权变化，删去依赖嘴角细节才能成立的摄影要求。若主要证据本来就是一句话中的微表情，应从合适的近距离构图设计，不为了套本例先拍一次挥击。

连续一镜内景别变化仍是同一个 Shot；允许且实际设计了切镜才增加 Shot。以上方法不改变逐字对白、既有剧情或生成授权，也不证明模型已能准确执行。

## 三种容易写错的边界

**变焦与位移**：固定机位变焦改变画角，不能绕开挡住目标的柱子；物理前移让近远层的透视关系变化。推拉变焦需要相机与焦段反向配合，主体画内大小近似稳定；不把普通推镜或随机背景变形叫作成功。技术术语的可执行性由实际模型和素材决定。

**运动、镜头效果与时间**：移轴/微缩是焦平面与尺度观感；延时是时间压缩；第一人称是观察视点。先确定这些效果，再另定相机静止、平移还是转动。无限缩放、地球尺度拉远和穿越实物属于特殊空间/合成表达，写明尺度节点或转场机制；不要把它们塞进现实连续镜头并同时要求“完全不穿物”。未请求此类效果的镜头仍遵守正常空间关系。

**方法与服务**：来源网站的生成按钮不是本项目的服务选择。继续沿用户指定/项目路线核对实际输入；不能因选择某种运动而换供应商、下载示例片、提交生成或宣称所有模型都能执行。需要生成时沿现有授权与任务机制，不新增自动重试。

**固定的参照系**：固定机位通常指相机相对场景不走位；随车厢、躯干或道具固定时，相机仍会随载体在世界中移动。转盘展示需分清物体自转与相机环绕：前者不应凭空要求静止背景产生相机环绕视差。滚转是相机绕镜头轴在时间中旋转，静态倾斜构图不自动意味着持续滚转。

遇到相近站点别名、车辆/主体锁定或特殊效果，按需查[Melies目录映射与转译示范](camera-movement-melies-map.md)；仍以自然语言写清摄影机、主体和环境各自的可见变化，不把目录术语当模型控制字段。

## 接到四宫格与模型正文

参考策略仍由[四宫格指南](four-panel-motion-storyboards.md)决定：简单摇摄、轻微推拉、单一反应可用单图；只有首尾需要约束时用支持的首尾帧；复杂绕行、遮挡后揭示或多阶段交互，需要明确中间状态时优先四状态。既有合格图复用。选用四格后保留一次生成4K整板再裁图规则，不因本模块给简单镜头增加图片任务。

四状态服务**同一条路径**：K01起态、K02经过关键地标、K03事实显露/动作转折、K04退出状态，取样按情节而非机械四等分。逐相邻状态写出三段连续过程，单一长镜头仍在一个 `[Shot 1]` 内；实际切镜才增加 Shot。四格不自动拥有控制相机轨迹的能力，未上传的图不写成已绑定参考。

H3沿用[既有编译结构](prompt-case-transfer-and-h3-compilation.md)：视觉、人物与相机同入 `integrated_multimodal_description`，声场与音乐各入原字段。图像标签以实际工作流暴露的格式和真实素材为准；不添加 `camera_move`、`movement`、`speed` 等未支持字段。其他模型沿自身模板，用同样的空间事实改写，不能强套 H3 结构。秒数和角度是导演目标，不保证逐帧执行；BPM仅在本片需要共同拍点时使用。

## 原创编译示范：横移揭示空位

锁定需求：6秒无对白、无音乐，一镜到底。站台女乘客原想把信交给等候的人，柱子后显露的是一张空长椅。重点是从期待转为空落；不增新角色或复杂动作。以下仅示范文生视频正文，不暗示已上传参考图或提交生成。

```text
integrated_multimodal_description:
[Shot 1] 00:00.000–00:06.000，连续一镜。黄昏站台，侧面中景，穿灰外套的女乘客站在画面左侧，右手垂握一封未封口的信；近景右侧的方柱挡住后方长椅。0–1秒，她的目光从信移到柱子后，相机保持原位。1–4秒，相机以起始朝向为基准沿站台向左平移，固定高度与焦段，镜头朝向不变；柱子相对后方墙面向画面右侧滑开，逐步露出既有长椅的空座。她双脚未动，只微微转头，右手收紧信封。相机在3.5秒起缓慢制动，4秒落定在她的侧脸与空座同框的位置。4–6秒保持这一构图，她的视线落到空座，手指略松、信封随手腕下沉；人物与信封仍在自然呼吸的微动中，画面不冻结。空座从显露到结尾始终可辨，光线与柱椅位置连续。

overall_soundscape: 远处列车低鸣持续，信纸随手指收紧出现轻微摩擦声；无对白。

non_diegetic_music: 无。
```

选横移是为了绕开遮挡，变焦无法完成。这个版本仅一次侧移与一次揭示，首态足够清楚且模式支持时可用单图；如果用户同时要求过门、绕人、转向并锁定多处中间站位，再使用四状态，不凭“揭示”二字机械触发。

## 修正时只改失效的一层

| 实际问题 | 先回查 | 范围内修正 |
| --- | --- | --- |
| 人物替相机倒退或转圈 | 主体/相机动作是否混写 | 分别描述两者路线及相对位置 |
| 推镜变成放大、横移变成摇头 | 运动机制与前景证据 | 指明固定焦段/固定机位及应有视差 |
| 绕柱后场景换了、人物变脸 | 路径、参考与不可见区域 | 补空间锚点或实际支持的状态参考；不把术语加长当修复 |
| 快速运动吞掉关键事实 | 加减速与阅读窗口 | 调整揭示落点；保留接触/表情的可读区间 |
| 四格变成轮播/溶解 | Shot划分、三段过程与真实绑定 | 同镜保持一Shot，写明连续动作并核对素材职责 |

文字审阅不等于生成验证。授权样片后按观看任务确认机制、方向、遮挡、落点、身份和接续是否做到；技术完成与效果通过分别记录，失败不自动重生。
