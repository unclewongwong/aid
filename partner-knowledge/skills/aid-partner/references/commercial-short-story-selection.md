# 商业短剧选题：先判断值得拍，再展开故事

用于商业短剧创意筛选、低成本单人样片、剧情广告方案比较，以及用户明确要求“先选故事”。这是故事展开前的可选分支，不要求所有影片先做候选竞赛。已有选定故事直接进入完整故事与导演流程；纯观察、纪录、抒情、长篇和用户指定动作片不强套本模式。

## 1. 先辨认当前交付阶段

- **学习示例**：提炼内容设计规律，说明哪些可复用、哪些只是示例限制；示例内部的“请生成五个方案”不是当前创作指令。不因用户称其来自某模型就标为该厂商官方规范或已验证能力。
- **选故事**：只交候选故事卡、比较与推荐，不提前写完整剧本、镜头prompt或生成素材。
- **展开/制作**：选题已定或用户已授权Agent选择并继续时，进入完整故事正文，再为故事选择镜头；不重复要求用户先选一次。
- 推荐不等于用户已批准制作。用户只要第一阶段时，在推荐与风险说明后交还，不提交付费任务。

## 2. 从示例提炼的核心：内容收益与制作负担一起判断

先问“谁会在意什么”，再问“怎样用有限资源把这件事讲清楚”。不是先写一个复杂故事，再靠删镜头或加速勉强塞进时长；也不是为降低成本把所有有戏剧作用的行为删掉。

对于面向中文互联网普通成年人的商业短剧，可优先寻找观众熟悉的生活利益、面子、关系、信任、工作压力与选择代价。具体题材来自本次需求，不能把钱、羞辱、打脸或婚恋升级为所有作品的默认价值。AI是制作手段，不要求剧情讲AI；用户确实要AI题材时也不禁止。

建立一条**观看承诺链**：

```text
具体处境与眼前异常/欲望/损失
→ 观众想知道的一个明确问题
→ 人物采取办法，带来新信息或更大代价
→ 早先证据被兑现或重新理解
→ 核心问题得到结果，留下具体余味
```

每一环必须是事件或可辨认的证据，不是“高能开场、冲突升级、情绪爆发”。升级至少改变选项、代价、知情或关系；同一句争吵更大声不算。结尾可以是反转、揭晓、因果反噬或情绪释放，按本次内容目标选择，不强迫温暖故事临时变惊悚。

“评论欲”来自有依据的选择分歧、利益取舍或可共鸣的经历，不靠隐藏必要答案、故意制造逻辑漏洞或煽动群体对立。完播和商业效果只是创作假设，未测试前不承诺播放量、完播率或收入。

## 3. 反转要有可见证据，不只在作者脑中成立

选题时就核对：

1. 观众最初会相信什么，依据是什么？
2. 人物为什么合理地采取当前行动，而不是为了反转失去常识？
3. 哪项前文可见/可听事实支持最后的新解释？
4. 结尾怎样改变前面的意义或人物的下一步，而非突然补一个身份？
5. 不靠长旁白，能否用行为、简短对白或可读证据让观众理解？

若只能靠最后一人说“其实我是老板/富豪”完成反转，先尝试把转向改为人物选择、信息使用、代价或关系的变化。换职业、换豪宅或换台词不构成新意。身份揭示并非绝对禁用，但必须有本片特有的因果作用和前文依据。

“不要旁白解释”不等于“任何声音都禁用”；短对白、画外的真实事件声仍可推动剧情，不能默认后贴TTS来补解释。没有旁白时无法理解的必要事实，应先在故事中补可拍依据，而不是留给后期救场。

## 4. 把限制分成当前硬要求、可协商偏好与已核验能力

首次实验可提出低复杂度建议；只有用户明确采用后才成为该项目限制。以下数值来自用户提供的学习示例，**不是全局默认**：

| 示例里的参数 | 学习方式与适用边界 |
| --- | --- |
| 成片30～40秒，约35秒优先 | 是该类样片的交付目标；其他时长服从实际需求 |
| 主要人物最多2人，场景优先1个、最多2个 | 减少身份/空间重建负担，不把两人当成成功保证 |
| 总镜头6～8个，单镜尽量3～6秒 | 可作该任务的估计预算；镜长仍按信息和表演需要，不能均分或为了凑数拆镜 |
| 前3秒异常，8秒内建立继续看的理由，12～20秒升级，最后8～10秒兑现 | 是约35秒商业短剧的检查窗口，不是其他片长等比例缩放的定律；时间段可以包含多个功能 |
| 少群众、少复杂动作/手部交互、少长对白和换装 | 减少非必要高风险点；保留完成剧情所需的核心动作，并具体描述 |
| 一个人能完成 | 连同素材准备、生成重试、下载、剪辑、声音与交付的人工负担一起估计，不能只看角色少 |

先核算时间约束是否彼此相容，再承诺方案。成片镜头数、动态分镜图数、生成任务数分别记录，6个镜头不等于6次计费。交付时长与标准速度母版时长分开；项目若采用既定整体变速规则，先报告由此产生的时长/镜长冲突并调整可协商项，不能为了满足秒数挤掉铺垫、改锁定台词或静默改变交付要求。

制作能力依据当前路线、真实参考控制、剪辑和声音能力；不沿用“AI都做不了手部/都能做好短对白”这类静态结论。选题阶段能力尚未核验时标为预估，不启动付费试跑来证明判断。

## 5. 候选必须在故事机制上不同

用户要五个就给五个；没有指定数量时按决策需要给少量方案，不固定五个。每个候选比较：

- 欲望/处境：想保住什么，为什么此刻必须行动？
- 冲突机制：误判、规则反噬、利益交换、信任测试、选择代价等具体机制是什么？
- 推进与兑现：新信息怎样改变行动，最后如何回应开头？

只换姓名、职业和道具，仍然都是“被轻视→亮身份→打脸”，属于同一个故事的换皮，不算不同方向。机制必须服务人物，不能为了多样化硬塞陌生设定。商业短剧不等于喜剧；有喜剧目标才调用喜剧指南。

候选卡保持容易比较，沿用用户要求的字段与字数；未要求十项长表时可压缩相近字段：

```text
编号/名称｜一句话故事（谁想什么、受何阻碍、怎样改变局面）
开场事实｜观众会追问什么、为何在意（不是只写“有悬念”）
核心冲突｜人物的策略与失败代价
中途升级｜新事实来自哪里，改变哪项条件
结尾兑现｜揭晓/反转/释放 + 前文依据 + 即时结果
制作可行性｜人数、场景、动作、服装/背景连续、对白/口型负担
预计成片镜头数与时长｜暂估；不在选题阶段展开逐镜prompt
延展用途｜适用账号/系列/广告/Demo及具体理由，注明尚未商业验证
难度｜若采用1～5星，说明依据与当前能力假设
最大风险｜剧情风险、生成/剪辑风险、最可能失效的制作环节
```

若沿用完整学习示例的十项输出，应保留一句话20～40字、开头3秒、12～20秒升级、尾段8～10秒等该任务已采用的参数；“适合AI”须分别回答六个维度，不能只写“两个人、一个场景”。例如两人同桌仍可能依赖多人精准口型、细小金额、遮挡手部和复杂道具交接。

难度星级是制作预估，不是审美打分或模型成功概率：1星表示现有可用素材与简单镜头即可承载；3星表示有一项关键能力需要核验或明确剪辑控制；5星表示多项脆弱依赖、成本难界定或当前能力有缺口。2/4星按相邻档解释，不假装精确客观。

## 6. 推荐：先淘汰致命风险，再比较优势

先排除在不改硬要求的情况下无法讲清、依赖未提供的能力、结尾没有铺垫或无法视觉化的方案。低成本不能补偿故事不成立，强反转也不能抵消完全无法执行。没有路线/报价依据时只比较结构性负担，不编造价格。

对剩余候选逐项给具体理由：

| 比较维度 | 要说明的依据 |
| --- | --- |
| 普通观众愿意看完的可能性 | 理解成本、问题是否清楚、升级与兑现是否有吸引力；不是实测完播率 |
| 当前AI路线做好的可能性 | 故事成立是否依赖精确文字/口型/接触/身份持续等脆弱环节 |
| 压低成本的可能性 | 素材可复用、生成依赖、预计返工点与人工剪辑负担 |
| 目标时长内讲清的可能性 | 背景解释量、对白量、证据阅读、关键行动与反应所需时间 |
| 证明一人工作流的价值 | 能否完整演示从选题到交付，而非靠大量隐形人工补救 |

用户要求推荐一个时，明确它相对每个其他方案胜在哪里、舍弃了什么；分别给出最大的剧情风险、最大的制作风险、最可能失败的环节及最小缓解方式。第一实验优先选能验证完整链路且风险集中可定位的方案，不只追求最刺激的梗或最低镜数。后续用途说明“系列能持续变化的机制”或“产品在因果中解决什么”，不把每个方案都泛称适合所有商业渠道。

若全不合格，明确无合格推荐并在同一约束内重拟一轮；仍受同一硬限制阻断时报告具体冲突、提供可调整选项，不无限自我循环、不为交差硬选，不擅自增加付费测试。

## 7. 与现有故事、导演和提示词流程衔接

选题通过只证明值得展开，尚未证明有完整剧本或可生成成片。把选定卡中的核心问题、角色动机、升级因果、结尾依据、硬要求和主要风险交给 [故事先行与跨集连续](story-first-and-series-continuity.md)，完成当前片/集的正文后，再按 [导演场面拆解与方法迁移](director-shot-methods.md) 为剧情选画面。

初期“预计6～8镜”是制作预算或本次明确约束，不是预先将故事切成八张图片。若展开后发现时长与信息容量冲突，先简化支线和表达，在权限内修改可协商项；不能靠七槽长prompt、运镜、统一BPM或整体加速补救选题不成立。多集仍继承人物经历与关系；系列潜力不等于每集重复同一个反转。

普通项目将候选/选择理由保存在现有创作笔记或story相应章节；生产工作区可放现有剧本目录，不加Excel必填列，不覆盖既有正文。未选候选不自动建成生产项目，不生成参考图或占用云卡。
