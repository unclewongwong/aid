# AIDP 本地综艺包装 · P01–P10

**是否包装与使用哪套风格分开。**只有用户在 Agent 中明确要求为本片加综艺包装（或明确要求人物条、环节卡等具体包装元素）才触发；选择近期默认或项目风格只保存偏好，不授权给后续视频自动加包装。没有包装指令时保持原有视频制作/合成流程，不追问、不添加，不因片型、笑点或已保存默认而推断需要。明确要求后，Agent 自动选方案并合成，不要求用户填 JSON、装 Node 或另配模型服务。按[综艺包装与片头](variety-show-packaging-and-titles.md)选择有用元素；不把包装理解为对白字幕、配乐或音效授权。

## 发现与选择

先核对当前会话是否暴露 `aid_packaging_catalog`、`aid_packaging_preview`、`aid_packaging_render`；存在时查询目录（已有项目传 `projectId`），核对 `available`、版本、风格和组件。本地包装已有素材不调用 `aid_route_plan`，也不因没有 API Key/共享通道而停止。只有另外需要生成底片时才走正常生成路线与授权。

工具缺失或引擎不可用时说明具体缺项；安装含包装引擎的 AIDP 应用、在首页更新已接入 Agent、重开会话后再核验。知识包只是指南，不能增加 MCP 工具、安装字体或执行代码；不能自动下载脚本绕过应用。旧工程维护可按需读[旧版独立工具](legacy-local-variety-packaging.md)，不要静默用旧视觉替换新风格。

这是包装编号，**不是 20 种影片画风编号**。十套均有 `lower-third` 人物条、`title` 短片头、`chapter` 环节卡、`pop` 强调字，均支持 16:9、9:16、1:1；目录是最终能力依据。没有自动人物跟踪、字幕识别、计分系统、双镜头转场或音乐功能，不虚构这些参数。

先判断用户是否明确要求本片综艺包装，再选择风格：本次明确选择/关闭 > 项目绑定/关闭 > 近期默认。通过 `aid_packaging_catalog(projectId)` 读取 `recentDefault` 和 `effective`；`effective.enabled` 只代表有可用风格，不代表获准包装。用户说“最近包装风格都用P07”时用 `aid_set_default_packaging({enabled:true,styleId:"P07"})` 保存偏好；仅本项目使用则用 `aid_set_packaging_style`，两者均不触发影片制作。清除近期默认用 enabled=false；项目停用同样用 enabled=false，恢复跟随默认用 styleId=null。用户已要求包装但没有可用风格时，请其选一次，不默选P01；无包装指令则不追问。

桌面选择路径：进入“包装”页 → 点卡片看动效 → “设为近期默认”。此后在 Agent 中说“这条视频加综艺包装”，才沿用已选风格并自动安排方案、组件、时间与导出；只说“做一条视频”不会加包装。只要求人物条时不扩展成全套花字或片头。手动编辑保留在“进阶编辑”，不是日常必经步骤。新默认不重做历史成片，也不改变已提交且明确授权的方案。

## 明确要求后的自动方案与合成

当前会话有 `aid_finalize_video` 且用户明确要求本片综艺包装时，Agent 查询目录并完成以下步骤，不向用户逐项追问。只有请求方案时只出方案，不提交渲染。旧工具可能默认沿用风格：未要求包装时若支持 `packaging.mode`，显式传 `off`；工具不支持且不能确认不会自动包装时不要调用它去交付普通视频。

1. 中间生成片段仍为原片；需要中间拼接的 `aid_compose` 传 `delivery:"intermediate"`，避免每段重复贴包装。
2. 所有剪辑和已确认的速度处理完成后，按**最终交付时间轴**安排必要的标题、人物条或环节事件。只用已确认文案；别照搬预览中的虚构姓名。人物身份不清楚就不造人物条。包装不能压过开头钩子或遮挡关键表演。
3. 调用 `aid_finalize_video`，传真实影片 `name`、`assetIds`、稳定 `idempotencyKey`、`packaging:{mode:"auto"}`，有项目则带 `projectId`。此处 auto 表示**已获本片包装指令后自动安排方案**，不是默认开启。已有可用风格时无需 styleId；本次指定风格才传。可在 `packaging.events` 提供 Agent 自行设计的最小事件时间线；只要求某种元素时必须用 events 限定范围，不以省略事件的片头替代。没提供 events 时引擎仅按真实片名做一段短片头，不自动编造人物/笑点/章节。任务名不适合上画时另传 `packaging.title`（1–40字）。
4. 用 `aid_task` 等到 completed，再通过 `aid_asset_path` 交付 `outputs` 的最终包装成片，不能交付尚未包装的母版。`originalOutputs` 保存原片。只有一个原片时直接包装，保持原尺寸/帧率/时长；多片段先沿当前合成的24fps规则拼接，再包装。已有包装的单片不会二次叠加；修改样式时改用它的原片。

`aid_compose` 与 `aid_finalize_video` 默认均不包装；仅显式 `packaging.mode:"auto"` 触发。styleId、title、events 本身不能代替该指令字段。未要求或本次拒绝包装时省略 packaging 或传 `packaging:{mode:"off"}`，不要清掉风格偏好。不要根据视频标题、故事文本或默认设置自行构造 auto。包装失败只恢复本地阶段，不重新调用付费生成、不重新下载通道视频。原片准备好且有明确指令时，failed 或 paused 可用 `aid_resume_task` 恢复。旧隐式自动包装任务会停止并保留原片，需明确要求后新建任务；版本缺失或原片变动也停止，不静默改风格。

旧应用没有自动交付工具时如实提示能力缺失，不声称设置已生效；不能以知识更新代替安装应用。

## 画幅与文字

字幕/标题及备用字形遵守[字体商用许可](font-commercial-licensing.md)。P01–P10 随包六款字体有 OFL 许可；保留许可文件，并核对实际文案字形覆盖，不能把浏览器隐式回退也算作已授权字体。

原片先用 `aid_import_asset` 得到真实 `sourceAssetId`。省略 `aspect`、尺寸、帧率、时长即跟随原片；标准比例为16:9、9:16、1:1。模板按画幅重排宽度、换行与位置，不把横版简单拉伸成竖版。跨比例时 `fit:"preserve"` 默认拒绝；只有明确选择才用 `contain` 完整画面加黑边，或 `cover` 居中裁切填满。没有智能主体追踪，不能说cover保证不裁人脸。

`safeArea` 为 `standard` 或 `social`；后者给竖屏右侧和底部多留空间，不是各平台永久安全区保证。`position` 为 `bottom-left`、`bottom-right`、`top-left`、`top-right`、`center`；结合实际镜头避开脸、已有字幕和重要物件。多事件按顺序叠加，不自动避碰，重叠时调整时间或位置。

每事件 `type/start/end/text` 必填，可选 `id/subtitle/label/position`。姓名、身份、评论、环节名来自已确认信息，不沿用样例人物。主文字最多24字（人物条）或40字（其余），副标题64字，小标签24字；实际排版过长会拒绝，不截字或缩成不可读小字。按观看任务减字/拆事件。入场约0.65秒、退场约0.45秒；1.6秒是技术最短，不是阅读建议。

## 进阶独立包装

需要代码化定制或任务卡、比分牌、角标时，可按[可编程 Variety Kit](programmable-variety-kit.md)核验已安装的独立模块。新版候选将片头与新包装的实际预览及默认放在同一个[App包装页](app-motion-library.md)，对应动效工具只按实际暴露能力调用。原P01–P10 render/preview spec保持独立，知识更新不安装执行资源。

用户明确要动效片头或动态字标时，按[动效片头与混合成片](motion-intros-and-hybrid-composition.md)区分本库短片头与定制代码制作。无原片的独立MP4可以插入正文前；有原片的标题只是叠加，不增加片长。已把片头合入成片后不再自动加第二个标题；指定片头不等于整片综艺包装。

用户明确授权相应包装且信息足够时，自己安排并提交，不再把技术步骤交回用户。通用视频制作授权不等于综艺包装授权；不能用独立渲染工具绕过上述边界。

1. 发现目录，采用已确认样式；导入原片，按真实秒数排时间。最终变速已完成则不再加速；包装自身不变速。
2. 用 `aid_packaging_preview` 生成代表时点PNG（传 `at`）。返回的是任务，用 `aid_task` 等待 `completed`，再 `aid_asset_path` 查看真实文字、遮挡和阅读窗口；不扩展为逐帧评分或自动重做整片。
3. 用 `aid_packaging_render` 提交同一时间线，新的稳定 `idempotencyKey` 区分预览与正式渲染。任务完成且有输出ID后取文件交付。MP4另存原片包装副本；无原片时生成独立片头。`format:"mov"` 是独立透明层，不能同时带原片；qtrle/argb MOV可导入支持该格式的剪辑软件，不承诺所有浏览器能播放。

示例只演示契约；素材、文案和时间须换成真实值：

```json
{
  "name": "本期嘉宾人物条",
  "idempotencyKey": "episode-01-guest-v1-render",
  "sourceAssetId": "实际导入返回的素材ID",
  "format": "mp4",
  "spec": {
    "version": "2.2.0",
    "styleId": "P02",
    "safeArea": "standard",
    "events": [
      {"id":"guest-1","type":"lower-third","start":1,"end":6,
       "text":"已确认姓名","subtitle":"已确认身份","label":"本期嘉宾","position":"bottom-left"}
    ]
  }
}
```

独立制作省略 `sourceAssetId`，用 `spec.duration` 和 `spec.aspect` 设总时长/画幅。一请求可含多个人物条、片头和环节事件。根请求支持 `projectId`；已绑定项目可省略 `spec.styleId`。时间线与模板版本保存于任务；改文案或风格用新编号、新任务，旧文件保留。

暂停用 `aid_pause_packaging`；原任务 `paused` 后用 `aid_resume_task` 从头重新渲染，不是帧级续传，不调用生成API。提交超时先查任务或以相同请求/编号取回，不换编号盲目重提；同编号配不同内容会报错。原片变化、模板版本缺失会停止，不静默升级重绘。

## 能力、许可与分发

2.2.0支持单次1.6–1800秒、1–128事件、最高4K、常规24/25/30/50/60及所支持的分数帧率；单原片包装保持尺寸/帧率/时长，输出重编码，不是无损封装。仅普通SDR、无旋转元数据、方形像素、最多单原音轨；多音轨/HDR等先明确制作母版。默认不添加音乐、音效、旁白或对白字幕，包装阶段不自动变速、超分或重新生成底片。

新库由应用分发引擎、Noto Sans SC OFL字体、原创布局和独立生成的透明装饰，保留许可与摘要，不分发用户参考图中的品牌、水印资产。Agent Skill只分发调用方法。源码测试、桌面运行、用户审美、安装版与公开发布分别报告；不能因本文就声称其他机器已安装或Intel/Windows已实测。
