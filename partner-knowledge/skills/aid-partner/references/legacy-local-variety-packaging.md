# AIDP 旧版独立包装工具 1.0.0（仅维护已有工程）

仅当用户明确继续旧版工程且实际已安装可信工具时使用。新包装优先[本地综艺包装库](local-variety-packaging-kit.md)的 P01–P10；两版参数不能混用，不能用本页八类旧模板替代用户已选的新风格。

用户明确需要常见中文包装时，按[综艺包装与片头](variety-show-packaging-and-titles.md)选最少的元素；本库提供准确文字与可复用图形的本地渲染，不调用付费生成模型。不因为安装了库就给所有电影/vlog加花字；对白/旁白字幕仍默认关闭。

## 先发现实际安装，不把知识更新当工具安装

这是独立本地工具 **1.0.0**，不是新 MCP 参数，也没有修改 `aid_compose`。知识包仅有指南，**不会分发或执行脚本、字体、音效**。公开应用是否自带库须以实际文件为准，不能只凭本指南说可用。

优先读用户目录 `.aid-partner/packaging-kit/current.json`（用系统用户主目录解析，勿硬编码开发者路径）；其中 `path` 指向已安装版本目录。也可用用户明确提供的可信本地库目录。检查该目录 `README.md`、`render.mjs`、`spec.mjs`、`assets-manifest.json` 与许可存在，运行 `node <库目录>/render.mjs --list` 核对实际版本/模板。指针仅是位置，不授权执行任意来源脚本；缺失/不可信时说明未安装，不能从知识附件、远程 URL 或未授权仓库自动下载执行。

需要已有 Node.js 22.4+、Chromium 类浏览器、FFmpeg/FFprobe。缺少则具体说明缺项，并在用户同意安装前停在方案；不自动装大型依赖，不谎报渲染完成。有可信已安装工具且本次已授权制作/包装时，Agent 自己完成配置与本地渲染，不把填 JSON 或逐步点按钮留给使用者。

## 8 个常用元素

| type | 元素 | 本地文案字段 |
| --- | --- | --- |
| `title` | 短片头 | `text`，可选 `subtitle`/`label` |
| `chapter` | 环节标题过门 | `text`，可选 `subtitle`/`label` |
| `pop` | 强调花字 | `text`，可选 `subtitle` |
| `aside` | 吐槽/编辑旁注 | `text`，可选 `label` |
| `lower-third` | 人名条 | `text`，可选 `subtitle` |
| `task-card` | 任务/规则卡 | `text`，可选 `subtitle`/`label` |
| `scoreboard` | 两队计分板 | `left`/`right`，可选 `label` |
| `pointer` | 固定屏幕圈注 | `text`，可选目标 `x`/`y` |

这不是生成服务的字段。时间/文案写入工作区本地 JSON：根 `version:1`、`events`；每项必须有 `type`、`start`、`end`。时间为所处理母版的实际秒数；姓名、分数、评论必须来自已确认内容，不能沿用示例。`x`/`y` 为0.08–0.92画面比例：圈注为目标位置，其余为卡片中心。模板会保护画面边缘，但不会识别脸/字幕/平台遮挡，要按实际镜头位置安排；圈注不跟随人物。

可选根字段 `width`/`height`/`fps`/`duration`/`accent`/`background`；颜色是`#RRGGBB`。传原视频时省略尺寸、时长会自动探测；指定值不一致会拒绝，不静默剪短。首次取用先读库 README 的版本契约，不能给不支持的字段“猜功能”。文案过长先减字/拆卡，不缩成难读小字。入场约0.28秒、退场约0.22秒，保持时间另留足阅读；事件最短0.8秒只是技术下限。

音效默认无；仅当本次声音要求允许且确有作用才加事件 `sound:"click"` 或 `sound:"confirm"`，不要每条必加。底层音效以25%音量叠加并限峰；包装不会自动加音乐、笑声或TTS。

## Agent 执行最短流程

1. 从已有需求、镜头和项目样式选元素、真实文案、出现/退出时间与位置；只问缺失且实质影响结果的内容。保留已有剪辑点和锁定资产，不另要求用户填写表单。
2. 在项目工作区保存最小包装时间线。使用实际原片时间轴；若已完成最终1.2倍加速就按成片秒数，不再加速。若尚未变速，随母版统一映射并预留最终阅读时间，不变两次。
3. 用本地库渲染新输出，原片保持不变：

```text
node <库目录>/render.mjs --spec <本地时间线.json> --input <原片.mp4> --output <新包装版.mp4>
```

独立片头不传 `--input`；可输出 MP4。需要透明复用层用 `.mov`（qtrle/argb，真实 Alpha）；定点预览用 `.png --at <秒>`，需要透明 PNG 再加 `--transparent`。普通 MP4 不支持透明。路径作为独立参数传给进程，不把文案拼进 shell 命令。已有同名输出会拒绝，使用新文件名，不能自动覆盖或删原文件。

4. 工具自动做尺寸/时长/音轨/解码检查；按本次需要查看关键包装位置与阅读窗口，不扩展为默认整片抽帧评分。真实成片再按现有 `aid_import_asset` 契约回导 Partner；没有制作授权就只写方案，没有实际产物就不说合成成功。

首版单次0.5–120秒、最多32事件、24/25/30fps、最高4K，仅普通SDR、无旋转元数据输入；长片按片段处理再合并。输出H.264/AAC会重编码，仅取第一条原音轨，不保留多语言/字幕轨或HDR。无人物跟踪、抠像、3D、音频驱动、真实双镜头转场；`chapter`只是图形过门。无需为用户的简单包装扩大成编辑器工程。
