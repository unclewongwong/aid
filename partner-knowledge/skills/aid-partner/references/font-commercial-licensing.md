# 字幕、标题与包装的字体商用许可

适用于已获准制作的字幕、标题、花字、人物条、角标、片头和 MG 文字。字体规则不额外授权添加这些元素，也不自动替换已交付影片。

## 选用与留证

只用许可明确覆盖本次商业用途的字体。优先采用来源可靠、许可随附的 SIL OFL 1.1 字体；免费商用的专有字体、已购字体或系统字体也可以使用，但须核对具体版本、来源、使用主体、用途和相应限制。**可商用不等于开源，安装成功不等于持有授权，代码开源不覆盖字体。**

在现有制作记录中简要保存字体家族/字重、实际文件与版本或 SHA-256、官方来源、许可证文件/授权依据、核验日期和使用场景。不要把购买凭据或个人信息写进公开 Skill。已有适用证据可复用，不反复向用户确认；资料不明时直接选用已核验的可商用替代。只有用户锁定特定字体且无法从已有资料确认权限时，询问缺失的许可信息；不自动购买授权。

区分交付方式：

- 字幕/片头烧录成视频像素，与交付字体文件、可编辑模板、网页/App/服务器嵌入是不同用途，逐项核对实际需要的权限。只交视频时不捎带不必要的字体文件。
- OFL 字体可用于商业设计与视频标题；作品不因使用它就必须开源，也不要求在视频中强行加字体署名。分发字体文件时保留对应版权声明和完整许可，不能单独售卖字体；修改/转换字体时另核对保留名称等条款。
- 系统字体不是通用开源资产。按字体来源及对应系统协议核验；Mac 上的可用权限不能自动扩展到 Linux 云渲染、Windows、App 随包分发或客户工程。某个系统字体获准使用不能替其他同名字体文件作证。

依据：[OFL 官方 FAQ](https://openfontlicense.org/ofl-faq/)、[Apple macOS Tahoe 26 协议 §2E](https://www.apple.com/legal/sla/docs/macOSTahoe.pdf)。系统协议随环境变化，使用时按实际版本核对。

## 实际渲染与回退

1. 核对执行器最终选中的文件，不只看设计稿里的字体名。中文、英文、数字、标点、各字重及 CJK 配对字体都适用同一许可要求。
2. FFmpeg/libass 使用明确的字体资源目录并检查 font selection 日志；Canvas/浏览器检查 FontFace 已加载和实际文本的字形覆盖；Pillow 检查文件与 TTC index。仅成功加载字体不能证明全部字符都来自该字体。
3. 缺字或缺文件时，只能回退到已核验字体；不能把系统自动回退或 `sans-serif` 当作已通过。输出有方框、替代字符、无法确认的备用字形时，先调整字体/回退配置再交付。
4. 换字体后检查换行、字号、文本宽度、安全区和动画裁边。许可合格不等于排版合格。

## 包装模块的已知边界（2026-10-27 审计）

这是日期化的配置审计，不是所有历史视频逐字形鉴定。以后仍以实际安装版和字体文件为准。

| 模块 | 发现 | 使用要求 |
| --- | --- | --- |
| P01–P10 经典包装 | 随包 Noto Sans SC、Noto Serif SC、得意黑、Archivo Black、Bebas Neue、Alfa Slab One 各有 OFL 1.1 许可；显式中文回退使用 Noto Sans SC | 可作为优先字体来源；仍检查实际文案缺字与浏览器隐式回退 |
| 旧版独立包装库 | 随包得意黑有 OFL 1.1 许可 | 不因此切换旧版视觉或自动安装旧引擎 |
| Variety Kit | 混用思源宋体、阿里普惠体、庞门正道标题体、站酷高端黑、汇文正楷、京華老宋体、系统西文字体与独立安装的 Helvetica Neue LT Std；缺文件会退到 STHeiti | **不是全开源字体栈**。逐一核验实际文件；通过 `fonts` 显式配置已核验字体及 CJK 别名，不照单沿用全部默认。免费商用声明不能代替标准开放许可或具体版本授权 |
| AFTERGLOW / Opus 片头 | AFTERGLOW 中文按内容选 Noto Sans SC，西文仍含 Helvetica Neue/Menlo；Opus 多数为 macOS 系统字体 | 中文标题使用开源字体不代表同片英文标签也开源；按实际文件与宿主协议核验 |

Variety Kit 的 `cond_black`、`cond_heavy`、`thin`、`light_w` 优先查找用户字体目录中的 Helvetica Neue LT Std 文件，它们不属于代码所指向的系统字体文件。没有该文件的适用授权依据时，配置已核验替代，不能用 Apple 系统字体协议替它背书。`CJK_PAIR` 及 `_FALLBACK` 同样需审查；`--check` 的文件存在检查不是许可审查。

知识更新只约束 Agent 的选字和验收，**不会修改已安装渲染器的默认字体、补齐许可证、安装字体或自动重渲染预览**。执行器若不能配置已核验字体，选择已有兼容方式；用户锁定该执行器时说明具体缺口，不冒称引擎已强制拦截。

字体来源核对入口：[Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)、[Noto Serif SC](https://github.com/google/fonts/tree/main/ofl/notoserifsc)、[得意黑](https://github.com/atelier-anchor/smiley-sans)、[思源宋体](https://github.com/adobe-fonts/source-han-serif)、[站酷官方字库](https://www.zcool.com.cn/special/zcoolfonts)。核对具体字体与版本，不把同一品牌的全部字体都列为免费或开源。
