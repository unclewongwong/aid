# 运镜技法速查

按要解决的观看问题检索，不把目录全部塞进一个 prompt。先选[运镜决策](camera-movement-story-decisions.md)，再用[编译指南](camera-movement-prompt-craft.md)补触发、起点、速度与终态。下表合并方向/速度变体为技法族，包含来源目录的常见叫法；不是46个执行器或模型专用语法。

## 固定支点、画角与焦点

| 检索名 | 要明确的控制量 | 适合与易错点 |
| --- | --- | --- |
| 固定镜头 / Static | 机身位置、朝向和取景保持；场内动作另写 | 让表演或空间关系自行展开；不要冻结主体 |
| 左/右摇摄 / Pan | 相机留在原支点，水平转向，给终点目标 | 沿视线连接同一地点；不能凭摇摄绕开实体遮挡 |
| 左/右甩镜 / Whip pan | 触发后迅速转向，制动并让目标可读 | 突发注意力转移；模糊段不放唯一关键线索 |
| 上/下摇摄 / Tilt | 支点不变，俯仰角变化，标明上下地标 | 沿人物/建筑纵向观察；不是机身升降 |
| 缓慢变焦推近/拉远 / Slow zoom in/out | 相机位置不动，画角缓变，目标画内占比随之改变 | 留时间观察范围变化；不许同时要求穿门或新视差 |
| 快速变焦推近/拉远 / Fast zoom in/out | 同为焦段变化，但较快到达目标景别 | 迅速强调或交代范围；到达后仍要能辨认 |
| 猛推/猛拉变焦 / Crash zoom in/out | 突发尺度重音及短促落点，机身不因此移动 | 喜剧/惊觉等重音按本片需要使用；不是随机震屏 |

“Fast”和“Crash”在自然语言模型里可能没有稳定的界线；写相对速度、触发与停点，不声称名称对应精确档位。拉焦与推拉变焦是原有指南中的补充技法，见[机制区分](camera-movement-story-decisions.md)，不混算为来源网站的46项。

## 机身位移与环绕

| 检索名 | 要明确的控制量 | 适合与易错点 |
| --- | --- | --- |
| 推轨接近/后退 / Dolly in/out | 机身沿前后路径移动；普通推轨保持焦段 | 前景视差和遮挡随距离变化；不能只做数字裁切 |
| 左/右横移 / Truck | 机身横向移动，朝向是否固定写清 | 绕开遮挡或读取并列关系；与Pan区别是位置真的变了 |
| 垂直升/降 / Pedestal | 整台相机改变高度，镜头俯仰是否保持另写 | 在不同高度看同一空间；不误作原地上/下摇 |
| 左/右短滑轨 / Slider | 短距离侧移、前中后层级、终点构图 | 小幅视差或精细展示；不要因为名叫滑轨就规定设备/厘米数 |
| 掠过前景 / Push past, pass-by | 从前景边缘或真实开口旁经过，写净空和遮挡次序 | 前景退开显露后方；默认不穿透实物 |
| 左/右弧线 / Arc | 绕行侧、有限弧段、半径/高度与看向目标 | 读取人物侧面或关系；不能让主体自己旋转来替代机位 |
| 顺/逆时针环绕 / Orbit | 俯视方向约定、起终位、所需弧度、相机朝向 | 需要持续改换观察角度时使用；不默认360°整圈 |

Arc与Orbit存在描述重叠，核心是实际弧段与观看任务。Orbit可以只走部分弧线；完整一圈要交代回到哪里、期间什么发生变化及足够的执行时间。

## 跟随与人体参照

| 检索名 | 要明确的控制量 | 适合与易错点 |
| --- | --- | --- |
| 跟踪 / Tracking | 主体路径和相机相对方位、距离、速度 | 是总体方法，不能代替具体前/后/侧位置 |
| 后方跟随 / Follow, over-the-shoulder | 相机在人物后方沿路走，人物朝向前方 | 共享人物正在进入的空间；肩后构图本身也可完全固定 |
| 前方倒退跟拍 / Reverse tracking, walk-and-talk | 人物向前，相机在前方同速后退 | 看走路中的表情/对白；不把人物也写成倒走 |
| 侧向跟拍 / Side tracking | 相机与主体平行前进，侧面或三分之四构图 | 保留行进代价与环境；区别于固定机位转头追人 |
| 低位跟拍 / Low tracking | 低机位沿动作路线移动、脚/轮接触与地面关系 | 看足步、轮子或近地动作；低机位本身不等于高速 |
| 车辆跟拍 / Vehicle tracking | 路线、车与相机的相对速度、道路地标 | 车可稳定在画内但地面/背景需正确运动；不增添危险动作 |
| 追逐镜头 / Chase | 追随方位、加减速原因、保持可读的对象 | 与动作连通；不等于默认剧烈手持或无因漂移 |
| 手持 / Handheld | 操作者站位、呼吸/步伐与克制微晃 | 需要身体观察感时用；不是所有片子的默认质感 |
| 身体固定 / Body-mounted, Snorricam | 相机相对躯干固定，人物动作带动背景 | 主体与背景相对运动反常的主观体验；不同于普通稳定器跟拍 |

## 空中视点与特殊表达

| 检索名 | 要明确的控制量 | 适合与易错点 |
| --- | --- | --- |
| 摇臂上升/下降 / Crane up/down | 真实抬升/下降的路径，可兼有弧线；朝向与可见层级另写 | 从个人扩到群体或落回细节；不必伪装纯直上直下 |
| 航拍推进/拉远 / Drone push in/pull back | 高度、飞行方向、目的地与沿路地标 | 建立地理关系；不是自动高速FPV或穿建筑 |
| 高空掠行 / Helicopter shot | 宽阔飞行路线、远景尺度、观察目标 | 大空间或移动地理；不靠名称添加直升机实体/声音 |
| 第一人称 / First-person view, POV | 谁在看、眼高、身体参照及主动动作 | 视点而非固定运镜；手臂是否入画由行为决定，不强制双手 |
| 移轴微缩 / Tilt-shift | 焦平面/清晰带与尺度观感；相机运动另外选 | 是光学/视觉效果；不把真实人物、建筑自动换成玩具模型 |
| 无限缩放 / Infinite zoom | 尺度层级、入口形状与跨层衔接方式 | 特殊转场/视觉世界；不是一台普通镜头无限变焦的物理保证 |
| 地球尺度拉远 / Earth zoom out | 起点→城市→地理→星球等必要尺度锚点 | 跨尺度表达按内容取节点；不据此宣称真实卫星/地理数据准确 |
| 延时 / Time-lapse | 时间压缩与变化对象，相机可固定也可另定路径 | 不是相机加速；如同时有对白/正常速度人物，需明确处理方式 |
| 穿越物体 / Pass-through objects | 真实开口、遮挡接镜或超现实穿透，选定一种机制 | 需说明壁面与到达空间如何连接；不同于从物体旁掠过 |

来源及未验证项见[编译指南的来源说明](camera-movement-prompt-craft.md#来源与适用范围)。技法定义和使用判断为原创整理；名称相同不构成模型执行保证，示例视频不随知识包分发。
