# 解释动画与艺术动态

用于白板推导、图形科普、数据讲解、软件教程、动态文字及艺术风格动画。先从用户要解释的内容和已有素材判断需要什么变化，再选择实现方式。叙事电影仍按故事因果与导演指南制作；本页不要求它们全部变成代码动画。

## 从信息任务选择画法

| 观众此刻需要理解什么 | 可选表达 | 画面怎样帮助理解 |
| --- | --- | --- |
| 原因、步骤、关系链 | 累积白板/关系图 | 随讲解依次加入节点和连线；已经建立的关系保留，必要时拉远看整体 |
| 抽象机制、计算或尺度 | 对象变形/示意模型 | 同一对象的状态变化承担推导；颜色、标签和对象身份前后可追认 |
| 历史、新闻或材料中的证据 | 截图/档案拼贴 | 先交代来源与上下文，再定位正在引用的具体区域；不制作假档案冒充证据 |
| 产品操作与教程 | 界面状态演示 | 让观众看清输入、操作和结果，关键控件保持可读；正式功能由实际素材支持 |
| 数量、趋势和对比 | 数据图表 | 先建立指标、单位与比较基准，再显示数据及相关注释 |
| 清单、章节或一句主张 | 动态文字 | 文案本身承担一个信息落点，出现、强调和离场跟随意义 |
| 风格本身的运动体验 | 艺术动态 | 把笔触、材料、图案或空间规则变成可见变化，保持构图和识别锚点 |

一段可以组合表达，但应清楚谁是当前主阅读对象。画法不由品牌名或名作者标签替代；例如“白板”需要有实际关系被建立，“数学动画”需要明确对象怎样变化。来源示范的秒数、镜头数、缓动曲线和色板不是本片配额。

## 先定承载信息的画面，再安排变化

沿用已有视觉契约、角色基准和用户锁定素材。没有视觉基准且方向确实未定时，可先设计代表性的状态或关键帧；已指定方向时直接在其约束内推进，不强制再生三套候选。

把构图拆成背景/空间、图形或道具、角色、精确文字与必要效果，明确哪些保持稳定、哪些在改变、改变带来什么新信息。无需为每层另做付费素材；分层只在实际编辑或控制需要时使用。艺术动画里，内部的墨迹扩散、光影变化、物体动作或构型变化应承担体验；只推拉整张静图或轮换图片，不能当作已完成要求中的内部动画。停驻可用于阅读和情绪，不要求每幕一直运动或添加固定数量循环。

参考动画的拆解沿用[证据与改编机制](story-dramaturgy.md)。分析实际媒体时分开相机运动、对象/材料运动和转场，选择能读清稳定状态的参考帧，避免把转场残留误认成正式造型。只有确实看过/测过的起止和运动才记为观察；图文介绍不能证明完整样片效果。精确拆解时可按实际素材提取局部帧与运动线索，固定帧差阈值不是跨片通用结论。

## 让讲解与视觉事件共用时间轴

有授权旁白时沿用[旁白与画面配对](narration-picture-pairing.md)，使用真实音轨的词句/停顿位置；仅写方案或没有音轨时标为预估。同步信息接入项目已有的逐秒/BPM表，不另建一套互相冲突的镜长。

为需要卡点的事件记录：**所对应词句/论点 → 内容何时首次可见 → 何时完整落定 → 可读停留 → 下一个状态**。这属于内部制作计划，不是新增的 MCP 字段。数字须在相关语言落点呈现正确终值时，由该落点倒推动画开始；不能让口播说完了数还在滚，也不能每次换景都把已经解释过的数从零重数。画完一整条清单的阅读窗口从最后一项落定开始算，不能把绘制过程全算作完整阅读时间。没有固定“晚半秒”规则，预先建立的图形也可以作为视觉铺垫。

累积白板先规划最终关系和空间，再按论证顺序展开；相机到达相关区域时观众应能看到第一笔或新节点。以笔尖领线的效果表现绘制时，揭示范围随实际笔尖路径前进，不能让线在其他位置自行出现。已经画出的信息在世界画布上保留，除非故事确实要求擦除或换页。读完前不把相机移走；相机已推近时，新高亮/注释应先进入当前可见区域再出现。

程序动画中的事件使用相对事件起点的时间，例如 `事件局部时间 = 全片时刻 − 段起点 − 段内事件起点`。步进姿势、描线与揭示从事件局部时间采样，避免按全片网格取整让对象提前露出；调整前段时长后，相同段内内容不应无故换相位。图形在世界空间，标题/已授权字幕的安全区在屏幕空间；推拉后重新检查对应关系，不能用初始坐标证明始终可读。

字幕继续默认关闭。图形标签用于解释对象和关系，不借动态文字把全部旁白换一种形式烧成字幕；用户未要求逐字字幕时不添加。已要求的字幕与图形文字按[包装信息轨道](ad-packaging-subtitles-and-graphics.md)避让。

## 角色分层与画风转换

生成图、既有角色帧与几何绘制按身份复杂度和实际控制需要选择，不要求所有人物都由代码或全部由生图承担。换画风时保留已确认的身份、比例、方向和当前动作状态，改变的是造型语言、线条与材质；不是随场景另造一个相似人物。

使用裁切后的角色帧时保留原画布尺寸、裁切偏移、缩放基准及脚底/手部等有效锚点。把帧放回同一空间后再控制运动；每帧按自己的紧包围盒居中会造成脚底滑动、人物大小跳变或手与道具脱离。镜像时一并变换锚点与道具接触点；姿势帧的数量与采样按需要确定，不强制八帧。透明抠图或色键处理不能以丢失头发、衣物边缘和身份细节换取“干净”。

画风决定的不只颜色，也包括笔触/图案的尺度、局部材料运动和如何建立新状态。角色、互动物件和背景分别负责哪些变化要明确；风格纹理若每帧无规律重抽会变成闪烁噪声。程序实现可用固定种子和时间函数区分稳定纹理与有意的笔触沸腾，确保重渲染同一时刻不会因前一帧状态残留改变结果。已有模型路线只能表达对应视觉意图，不能据此保证逐像素一致。

## 代码画面可从任意时刻重现

选定代码动画路线时，画面由指定时间与固定输入求得，不依赖播放到前一帧、系统当前时钟或未设种子的随机数；先渲染中段，再回到开头，结果应与顺序渲染相同。人物姿态、相机、受光与附着效果读取同一时间轴，各层可按风格采用自己的采样节奏。场景确需模拟时，先生成可回读的轨迹/状态或固定步长缓存，再按时间读取，不能让并行导出或跳帧预览改变剧情状态。

正式抓帧前等待所用字体、图像与必要的预计算状态就绪；缺资源应报告具体项，不能把占位字体、空角色或半加载画面写进成片。跟随人物的光圈、标记、局部放大框和接触效果，通过同一套当前相机的世界到屏幕变换定位；不手填一次屏幕坐标后任相机离开。标签、标题等屏幕信息与物体锚点分别管理。

本节是实际代码工程的可靠性要求，不把上游函数名或渲染接口加进 Partner 的 MCP；生成视频仍按真实模型能力表达视觉目标。

## 数据与准确文字

图表使用已给定或已核验的数据、单位、时间范围和来源；示意数字明确标为示意。动画只控制怎样显示，不能改变最终数值或给截图补造事实。柱形长度表示数量时保持合理的零基准；需要非零轴的趋势图明确尺度。刻度、曲线/柱形、注释与口播终值一致，“涨到几倍”与“增加几倍”分别计算。

形变只有在量纲、对象和对应关系成立时才表示转换。营收柱直接变成股价线可能暗示不存在的单位或因果关系，应明确换指标并重建坐标；概念色和标签在对象变化中维持同一含义。精确数据、公式、中文、品牌文字优先由可控图形/编辑层承担，不让视频模型随机绘字作为准确证明。标题、单位、来源与被强调对象都需有真实阅读空间，放不下时优先重排或减少同时呈现内容，不能无限缩字。

选择等轴信息图时先锁投影与轴向，平移、推拉和对象运动仍沿这套空间关系，不能靠任意环绕改变原有轴线。路线、定位圈和引线附着在所解释的对象上；局部细节太小时，可用连接明确的放大窗同时保留全局关系。用重复图标表达数量时，给出每个图标代表的单位，保持同组图标等大，数量与显示总值一致；仅作氛围的装饰图标不冒充定量证据。颜色用于指认当前对象与上下文，不能在强调后改变原来的图例含义。

## 执行与交付边界

实现可选当前可用的模型生成、代码绘制、分层素材合成或混合；按用户选定路线、目标及实际工具决定，不因参考 Skill 使用 Canvas 就静默更换 H3 服务。复用已有可用渲染能力，知识学习不自动安装上游引擎、字体、浏览器或采样包，也不自动追加配乐/生图费用。

代码动画若实际制作，由 Agent 在项目的可编辑工程中实现并用已核验的本地工具导出；保留时间轴、素材和参数，导入真实输出文件到 Partner。当前 `aid_generate` 与 `aid_compose` 不因此增加动画 `spec`、任意混音、透明视频或精准帧编辑参数；不能直接调用上游示例函数并假定它已安装。首尾同帧可以是一个循环意图，但不能承诺视频模型必然返回无缝循环。

检查范围沿用[制作放行与修订](production-acceptance-and-revision.md)。默认做文件、实际规格、音画时间与素材齐全的技术核对；用户要求某项或指出具体问题后，再看相应阅读窗口、定位、交互和接缝。静止比例或帧差只提供线索，阅读停驻、有意硬切和节拍变化不能自动判坏；不沿用上游强制自动审片、总分或循环重做。方法与本片验证结论分开，未渲染的方案不能称为已经出片。
