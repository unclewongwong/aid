# 故事先行与跨集连续：先讲完整，再决定怎样拍

用于原创或扩写叙事、完整剧本、多集项目、长篇分批创作，以及用户指出“碎、前后不连贯、只有画面没有故事”。这是分镜前的写作流程，不是要求用户多填表。Agent负责整理与回写；普通短片可将成果放在同一份文档，不增加不必要文件。

## 1. 三层成果不能互相替代

1. **整体故事**：当前作品从什么处境开始，人物为什么行动，怎样越陷越深或改变理解，作出什么决定，最终留下什么结果。多集先有系列总纲与分集走向。
2. **故事正文**：用场景、具体事件、行动、必要对白和后果，讲完当前交付范围。不含摄影词也应能读懂、产生期待并感受到收束；故事卡、节拍表和画面清单都不等于完整剧本。
3. **导演表达稿**：从已成立的故事选择观众此刻应该看见、听见、暂不知道什么，再决定拍人物、反应、物件、环境、画外事件还是过渡。最后才进入镜号、秒数、BPM、动作参数和模型提示词。

视觉灵感可以早出现，先记为候选，不让一幅漂亮画面反过来逼故事凑情节。现成完整剧本直接建立映射，不为了补齐流程重写用户锁定内容；发现结构问题只在授权范围内修改。

## 2. 把“起承转合、勾人、爱看”写成具体事件

先用一段口述故事确定从开头到结局的方向，再展开场景。故事契约与人物因果沿用 [故事与剧本](story-dramaturgy.md)，这里要求把它们变成真正可读的正文。

| 写作问题 | 需要在故事里实际发生什么 |
| --- | --- |
| 为什么跟着这个人看？ | 很早就让观众看见一项具体欲望、困境、矛盾或关系，明白他有什么值得争取或失去。不能只介绍身份。 |
| 为什么还想看下一段？ | 留下明确的担心、期待、好奇或情感张力；当前行动给出部分结果，同时改变下一步条件。不只写“这里很抓人”。 |
| 怎样递进而非重复？ | 旧办法受到反制；新办法改变筹码、认知或关系，带来新的成本。不能把同一种失败换地点重演。 |
| 转折改变了什么？ | 已铺垫事实使人物必须改判断、改策略或承担选择。反转不是必需，更不是临时增加陌生危机。 |
| 结尾为什么满足？ | 开场的核心期待得到结果，人物承担此前行动的后果；开放结尾可以保留答案，但已经发生的变化与代价须清楚。 |

这些是观看体验，不是四等分时长、固定三幕比例或每镜一个爆点。温柔故事可以靠亲密与期待吸引人，观察片可以靠发现与过程成立，不强造反派和成长。人物不必胜利或变好；悲剧、失败、反讽也应有完整的发展。不能用“她终于懂得爱”代替让她作出与开头不同且有代价的选择。

## 3. 内容太长时：大纲完整，正文分批，不能边写边失忆

先为本次约定范围写到结尾的整体大纲：主要阶段、转向、每阶段的结果、关键铺垫及其兑现、最终方向。系列尚未约定总集数时，只规划已约定季/批次的走向，不虚构无限续集的确定结局。

再按自然场景或集逐批展开正文；每批有稳定的场景/剧情拍ID，并关联大纲。不要把视频模型的15秒容量当写作分批标准。每次继续前读取并在结束后更新：

```text
当前采用的总纲版本与已锁定事实
本批对应的大纲阶段、剧情拍ID及必须达到的结果
上一批最后的事件与人物/关系/知情/道具状态
当前仍有效的铺垫、承诺与其计划兑现位置
本批具体正文
本批实际退出状态、变更项、下一批入口及尚未写完的范围
```

大纲是约束和导航，不是不能修订。更好的发展若改变结局、既有事实或后续依赖，在允许范围内先更新总纲和受影响部分；不暗中在后文另起故事。已锁定内容需新授权时明确列出冲突。草案中计划会发生的事不能冒充前文已经发生的事实。

**写作可渐进，交付不能冒充完整。** 只完成大纲就标“大纲”；只有部分正文就标已完成范围。开始制作某一集/单片前，该集/单片的故事正文、逐秒视听设计与所需代表性分镜须完整。系列不必等所有集的逐秒稿和图片完成才生成第一集，但必须先有系列大纲及跨集约束；不把半集当一集来绕过整片准备。

## 4. 多集不是重复角色卡，而是共同生活留下痕迹

从需求判断系列类型；信息足够时直接判断并注明，不让用户填复杂配置：

- **独立单元、同一世界与人物**：本集事件闭环，但人物记得经历，关系、习惯、承诺、工作或生活处境保留影响。下一集可以换事件，不必承接最后一秒，更不必每集悬崖结尾。
- **连续长线**：本集有局部结果，同时推动跨集目标、关系或矛盾；上一集后果直接改变本集入口。支线回到主线要有事件或意义关系，不轮流展示人物。
- **选集/主题合集**：若用户明确各集不同人物与世界，可用主题问题、叙述视角或视觉母题形成整体；不强造同一角色历史。统一滤镜不能冒充剧情连续。

在系列总纲中保存：系列承诺与类型、稳定世界规则、人物关系与惯常策略、允许变化的长线、已约定分集走向。每集用一行概括：

```text
集号 | 承接的既成事实 | 本集目标/事件 | 主要选择与结果 | 本集兑现 | 留给后集的变化
```

这里的承接可以是债务、新的信任边界、失败教训、公开名声、习惯变化，或同一场景中有历史意义的物件；不是在片头强加“上集回顾”。旧观众能认出关系积累，新观众也应从本集行动理解眼前事件。

每集完成文字修订后更新一次连续性记录：人物目标/关系变化、谁知道或误信什么、承诺与已付代价、重要物件/伤势/地点状态、尚未兑现的铺垫、下集采用哪些事实。事实指明来自哪个集/场景，并区分“正文已确定”“计划”“成片实际偏差”。后集引用前集的变化，不复位、不无故失忆，也不强迫每条旧线索立即回收。

例如原创双集喜剧：第一集，室友为掩盖自己忘带钥匙，谎称门锁损坏，坚持自行修锁，反而真把锁弄坏；最后承认并答应支付维修费。本集笑点和责任已经闭环。第二集改讲合租聚餐，他为省下维修费抢着掌勺，却拒买食材；同伴不再接受他“全包”的口头保证，要求先看购物袋。新事件独立成立，花钱压力与信任变化来自前集，而非只复用同一套公寓。

## 5. 故事到镜头必须有可追溯的表达决策

为主要场景/转折保留下面的简短映射，细节方法见 [导演视觉叙事](director-storytelling-and-shot-causality.md)：

```text
剧情拍ID与故事事件
→ 观众当前知道/期待什么，本拍结束要理解/感受什么
→ 表达选择：拍什么、站在哪一方看、先给什么、暂不展示什么
→ 为什么这个选择比直接拍说话者或动作全程更合适（若直接拍最好就直接拍）
→ 对应镜号及视听证据
→ 退出状态与下一拍如何接住
```

关键揭示、转折或复杂关系段落，先比较至少两种合理表达，再选择一种；普通连接段不机械生成多套方案。可以比较正面表演与听者反应、当场行动与结果痕迹、同框关系与分切视点、直接换场与声音先行。比较的是信息和感受，不是“哪个更炫”。

**不是每句话配一镜、每个名词配一图、每个剧情拍切一次。** 多拍可在一个镜头内通过调度完成；一拍也可用建立、细节与反应数镜完成。无须把所有导演分析交给视频模型，真正执行的可见/可听内容才编译到prompt。

## 6. 三层放行与保存

- **故事层**：隐藏摄影和美术描述，是否仍有可复述、完整且值得等待的事件发展？主要选择与结局有没有依据？只有“遭遇困难、逐渐成长”的大纲不能充作剧本。
- **系列层**：后集是否使用了仍有效的历史？本集事件是否有结果？脱离前集能理解眼前事件吗？独立单元不因强行吊胃口失去收束，连续长线不因分集重新归零。
- **表达层**：镜头能回指具体剧情拍、情感/信息任务与可见证据吗？删掉它是否损害因果、空间理解、预期、关系、情绪或必要余波？有功能的静止与消化不因“不推动物理动作”被删。

上游没通过先改上游；不把七槽动作、BPM、四宫格、转场和长提示词当作故事完整性的替代。这是生成前文字复核，不新增自动审美评分或付费重做。

工作区沿用现有`制作资料/剧本`、`制作资料/分镜`等目录：总纲和连续性记录放在剧本目录，本集正文放在该集现有目录；导演表达映射放该集分镜稿。不改编剧需求Excel、不增加必填列、不覆盖已有正文。普通Partner项目使用现有`story`保存分节文本和ID映射；系列工具可用时通过其真实字段关联各集，否则保存文件并明确未同步，不能发明API字段或把系列总纲写成仅在聊天中存在。

## 研究依据与边界

2026-09-25查阅[Paul Schrader的BAFTA编剧讲座](https://www.bafta.org/media-centre/press-releases/bafta-screenwriters-lecture-series-paul-schrader/)：他讲述先口述故事、观察听者注意力，再反复调整大纲并发展成剧本。这里将其启发转化为“普通语言故事→结构修订→正文”的工作顺序；Agent推演观众反应不能声称已经做过真人观众测试。分批交接、跨集台账和Partner保存方式是针对用户反馈的本地工作设计，不是该讲座的原文或导演通用硬公式。
