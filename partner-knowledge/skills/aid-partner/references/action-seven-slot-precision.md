# 动作七槽：把每条动作写成可执行指令

用于视频提示词、动态分镜、人物调度、打斗、道具交互、对白伴随动作和任何需要模型在时间中执行的动作。目标是把剧本中的意图编译成能被看见、定位、计时和验收的身体运动，不用文学化形容词代替编排。七槽是 [提示词参数语法](prompt-parameterization-grammar.md) 在人物/生物/机械动作上的专用格式；光线、阴影、摄影机、焦点和材质使用同一总语法的领域参数包。

## 1. 七槽是每条动作的最小契约

每条需要模型执行、维持连续或交给下一拍的动作，都要写满七个槽位。可以写成一句自然语言，但不能缺信息。

| 槽位 | 必须回答 | 合格写法 |
| --- | --- | --- |
| 1. 主体 | 谁在动？ | 稳定角色ID，如`S1`、`S2`；多人同镜不用“她/他/对方”猜测 |
| 2. 执行部位 | 身体哪个精确部位在动？ | `右手食指`、`左前臂`、`头部`、`右脚脚掌`；必须落到左/右或明确解剖区域 |
| 3. 可视动词 | 部位具体做什么？ | `抬起`、`屈曲`、`按压`、`旋转`、`松开`、`踏地`；不用“比划、挣扎、带着情绪地动”代替 |
| 4. 对象与接触点 | 作用于谁/什么，从哪里接触？ | `右手食指指腹接触玻璃杯身外侧中部`；落空时写明目标与最近距离 |
| 5. 运动方式 | 向哪里、移动多少、多快，速度如何变化？ | `沿杯壁垂直向上3厘米，0.2秒加速后匀速，到点用0.1秒减速停住` |
| 6. 次数/时长 | 做几下、几次或持续多久？ | `点两下，每次0.15秒，间隔0.45秒`；单次也写`1次，历时0.8秒` |
| 7. 起止状态 | 开始前是什么状态，结束后什么改变？道具归属呢？ | `开始时右手垂在S1身体右侧；结束时右手收回同侧且不再接触杯子，左手全程持杯不松手` |

七槽写满才能提交。“S1轻轻敲了敲杯子”仍不合格：它没有说哪只手的哪个部位、接触杯子哪里、运动路径和幅度、几下、间隔、以及动作前后持物关系。

## 2. 先定义左右和归属，再写动作

- 角色的左/右默认按该角色自身解剖方向，不随反打、角色转身或画面左右改变。需要描述构图时，另写“画面左侧/画面右侧”，不与解剖左右混用。
- 某只手、脚、触手、翼、机械臂或其他执行部位首次出现时必须定义，之后每次都使用同一标识。不写“空着的那只手”、“另一只手”、“对面那条腿”。
- 每个重要道具在本拍只有一个持有者或明确支撑面。不换手、不离手、不放下、不交接时，用正向句写“S1左手全程环握杯柄，杯子相对左掌不位移”。
- 需要双手同时作用时，分别给左手和右手写七槽，明确主动手、稳定手和各自接触点。不用“双手配合”代替两条动作。

## 3. 文学化语言可以表达意图，不能独自指挥动作

“轻轻、缓缓、果断地、带着压迫感、像被刺痛一样、充满爱意地、下意识地、优雅地”可以作为表演意图，但必须编译为可见参数。例如：

| 不可执行 | 可执行改写 |
| --- | --- |
| `S1缓缓转身` | `S1以左脚前掌为轴，右脚向身后划半圆移动一个肩宽，骨盆先转30度、肩线再追随转到90度，全程1.2秒，前0.8秒匀速、末0.4秒减速站稳` |
| `S1愤怒地指着S2` | `S1右肘从身侧屈臂抬至肩高，右食指伸直、指尖停在距S2胸口40厘米处，手臂在0.25秒内快速到位并保持0.7秒；同时下颌前送、眉间收紧` |
| `S1挣扎着脱身` | `S1右手手腕先逆时针旋转45度去对准S2拇指缺口，再向自己右下方抽离20厘米；抽离共1次、历时0.5秒，结束时S2右手与S1手腕完全分离` |
| `S1比划一下` | 先决定信息目标，再写精确手势；若无法说明手掌朝向、手指形状、路径、幅度和停留时间，删除这个动作 |

先保留剧作意图，再用身体事实实现它。成稿可以写“克制的愤怒”，但后面必须紧跟下颌、眉眼、呼吸、肩背、手臂和触点的可见变化。

## 4. 把大动作拆成可执行的原子动作

“走到门口拿起包再回头看他”包含多个接触、重心和目标变化，不能只填一次七槽。按状态转折拆分：

1. S1从当前站位走到门口；
2. S1停稳并把重心移到左脚；
3. S1右手伸向包柄并建立接触；
4. S1右手合拢握住包柄并把包离地；
5. S1保持右手持包，先移动眼神、再转头看向S2。

每条原子动作分别写七槽，并让前一条的结束状态成为后一条的开始状态。动作间若需要同时发生，分别写七槽后再指定并行时段，不把两条行为混成“一边……一边……”。

拆解外部动作参考时，先把**镜头事实、执行者运动、受作用物变化**分开记录：机位/景别和切镜是否变化；身体部位如何移动、转向或转移重心；接触点何时建立，物体哪一部分先受力、怎样变形/位移、最后在哪里停住。不要从参考视频继承陌生人的身份、脸、服装或与本片无关的镜头风格。编写本片的连续动作时，在每个必要的接触与状态转折处成对核对“人正在做什么／物体此刻变成什么”，并让上一对终态成为下一对初态；里程碑数量由实际动作决定，不固定四步。这是提交前的时序审计，不额外开启生成后逐帧质检。

方法启发：[路飞 AI 研究员《AI 短视频实战：36 条视频涨 70 万粉》](https://mp.weixin.qq.com/s/HC8XaZucfFWXJvSubDNbZA)中的分层观察和人—物配对里程碑；以上为 Partner 按既有七槽与素材职责原创整理，未复用原文人物、数值或固定步骤。

## 5. 表情、非人角色和镜头运动也要精确

- **表情**：主体是角色ID；执行部位是眼睑、眉间、眼球、嘴角、下颌、舌/唇或呼吸区域；对象可为视线目标或刚发生的事实。“震惊”不是动作，眼睑在0.15秒内从当前开合度扩大、下颌下沉和吸气中断才是。
- **微表演时序**：单镜只靠细微表情承载剧情时，先写稳定起态与触发，再把视线、眼睑、眉唇、呼吸、头部分为实际需要的先后/并行阶段；写清每一阶段的启动、延迟、幅度、停留与结束状态。视线要指向画内道具、画外人物或有空间方位的目标，不只写“看向画面下方”。给观众辨认变化的短暂停驻，再决定回到起态还是留下情绪痕迹；不为了填满秒数而反复眨眼、摆头。眼球先于头部适用于某些迟疑或发现，不是所有情绪的固定顺序。极近特写可有意裁去额头或下巴，但真正承载变化的眼、嘴及相应接触/光点必须可辨。身份、发型、服装、表情基线和受光位置随表演连续，不把“真实皮肤”写成每个毛孔都同时清晰的无目的清单。
- **非人角色**：按真实结构把翅、鳍、触手、尾、外骨骼、机械关节或软体区域作为执行部位；不强行套用人手、人脚或人类关节幅度。
- **摄影机**：不套人体七槽，但使用对应的七项运镜契约：起位与当前构图、故事触发、物理路径/方向、距离或角度、速度曲线、持续时间/拍点、制动落点与最终构图。
- **静态生图**：不伪造未来动作；写清当前角色ID、左右肢体、关节角度/朝向、对象与接触点、用力或重心、此刻持续的接触关系及道具归属，让该图成为视频动作的可靠起点。

## 6. 提交前逐条审计

对实际`prompt`中每条人物/生物/机械动作打勾：

1. 是否有稳定主体ID？
2. 是否精确到左/右或具体执行部位？
3. 是否是能直接看见的动词？
4. 是否有对象、接触面/接触点，或明确落空关系？
5. 是否有方向、幅度/距离、速度及必要的加减速？
6. 是否有次数或持续时间？
7. 是否写明动作前后状态、接触关系和道具归属？

再做全局审计：左右是否全段稳定；是否出现“另一只、空着的、对方的”等相对指代；同一道具是否被两人或两只手无原因同时占有；后一条动作是否真实继承前一条的结束状态。任一缺失就退回提示词阶段，不得用“动作自然、连贯、优雅、有力、充满情绪”等形容词补空。
