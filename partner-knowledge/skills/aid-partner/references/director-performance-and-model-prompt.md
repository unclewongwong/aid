# 从导演意图到表演和视频提示词

用于对手戏、复杂表演、连续调度和提示词细节不足的修订。先遵守已有剧本、逐字台词、已锁镜头与制作范围；简单展示或无人物镜头跳过不适用项。不要求另建表格或审批，也不以字数保证效果。

## 先导演，再安排可见表演

先确定这一拍观众要观察谁、理解或感受什么，哪些信息先知道、哪些稍后揭示，何处需要消化时间。再按空间中的门、障碍、物件和人物站位安排走位，确定景别与观看位置。调度、景别、声画变化是可选工具而非固定含义：同一个后退可能是害怕、礼让或为别人让路，必须结合人物关系与剧情。

主要角色有明确意图时，先想清**想达成什么、眼前阻碍是什么、眼下采用什么策略、何时因对方或事件改变策略**。意图可以针对自己、环境或另一个人；观察式影像、仪式或纯动作不强套对抗。潜台词可保留在导演说明里，再选适合人物性格、压抑程度、关系和景别的可见行为表达：视线停留或移开、动作迟疑与收回、呼吸、重心、手与物件的接触等。情绪词可以辅助表达，但不能代替决定剧情的具体反应。

听者并非一定要动：他可能继续手上的任务、压住回应或改变策略。重要信息出现时，按戏的需要安排察觉、理解、决定和行动的先后；允许其中一些瞬间重合、省略或保持模糊，不规定固定时长。群体可有同步动作，也可分先后反应；依据事件和关系编排，不默认统一抬头。台词前、中、后按需要保留视线、动作、停顿与说话空间，不机械为每句增加小动作。静止与留白可以是有意的表演。

## 五个维度核对实际提交稿

针对全段按时间和叙事节点检查，不必输出一张每秒必填的表。导演稿不能代替模型收到的正文；按镜头实际需要，把下列内容完整写入实际 `prompt`，不适用的维度可以省略，恒定状态可集中声明一次：

1. **主体与道具**：从什么姿态或位置开始，由什么触发，身体哪一部分以什么方向、力度和速度经过怎样的路径，何时接触、受力、收势，结束后道具由谁持有。
2. **表情与视线**：察觉对象、视线落点和变化，与说话或身体动作的先后；有意义的停顿和克制也写清。关键表情必须能在所选景别、焦点和遮挡条件下被看见。
3. **对手与环境**：另一人何时回应或为何保持，门、布料、物件、背景与光线因事件如何变化；固定场景不必每秒重写。前后段的进入与退出状态能接得上。
4. **摄影与观看**：摄影机起位、主体可读范围、运动动机、路径、速度变化、焦点与构图落点；固定镜头说明要观察什么。连续机位的推、停、转向和后退可以是同一镜的多个阶段，不自动改成硬切。
5. **声音与对白**：逐字台词、说话人、必要的停顿，触发于动作的拟音及必要环境声；音乐、配音、静音和字幕以本次需求与接口能力为准。声音不存在或计划另做时不虚构已生成。

按复杂度展开：一个关键动作可细到一秒内多个阶段或更小时间点，15秒复杂场景需要千字级描述时写足；简单镜头不为密度补无意义运动。不强制每秒两项变化、不强制每秒五轨都有新信息，也不将示例字数、厘米或小数秒当精度保证。景别中看不到的细节，不要当作观众必读的线索；必要时调整构图或真实切镜。合并重复恒定设定，保护重要变化、接触、对白、视线和退出状态；实际模型的负荷仍要依据结果判断，不自动增加付费任务。

### 简短示意：表演与运镜怎样配合

女孩想让父亲接住自己递出的信，父亲想回避。中近景中，她从桌面拿起信，抬眼看向父亲；右臂向前伸到两人之间，却在他把手收回时停住。她原本急切的嘴角慢慢收紧，视线落到他空着的手，再看回他的脸。父亲没有接信，手指贴在桌沿；远处门外传来脚步，他才侧头看向门口。摄影机开始保持双人关系，女孩停手后沿桌边轻推，让递出的信和父亲空着的手同时可读，最后停在两人之间；桌布摩擦与画外脚步分别跟随接触和触发。示意说明谁做了什么、对方怎样回应、相机为了看清什么而动；实际拍摄需按故事补足节拍、时间、参考和段末状态，不把该例当现成完整模型稿。

## 编译成当前路线支持的形式

先用 `aid_workflows`、当前工具和只读请求预览确认模式、真实素材顺序、各素材职责与字段；引用实际存在的图号。切镜、同镜内部阶段和一次生成任务是三种不同概念。用户锁定无剪辑时不为简化提示词假装新增镜头；若模型难以承载，先按授权调整走位或表达，仍不满足时说明限制。

- **MiniMax H3 官方提示词格式**：官方写作指南建议视觉和声景正文用英文，对白、歌词与画面文字保留原文；有明确用户语言要求、锁定同稿或具体适配器约定时优先。英文是写作建议，不宣称中文无法使用。基础模式和完整参考模式的格式不同，只在实际路线支持时采用；不把提示词内标题当成新增 API 字段。
- **Seedance 2.0 系列**：官方建议尽量简化同镜运镜以降低不稳定，并说明强制精确秒数可能不稳定。可突出主运镜，用顺序、同时和先后描述阶段；明确需要连续复合运动时保留其连贯路径，不能把阶段伪装为硬切。素材按实际上传编号标明用途；编辑/延长与参考任务的输入含义不同，以真实接口为准。不要因第三方经验擅自替换逐字对白、删除固定帧数或给参考数量和提示词长度设硬阈值。
- **Seedance 2.5 与 2.0 区分**：官方指南称 2.5 可响应整数秒时间戳，也支持主体多视图；2.0 的精确时间支持不稳定，且官方不建议把同一人物多角度拼到一张参考图中。是否接入 2.5、多视图及具体素材数量仍以当前请求预览为准，不把新版能力套给旧版或当成准确切帧保证。参考 [Seedance 2.5 提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)。
- **节拍不丢失**：叙事段仍按现行[逐秒视听](whole-film-second-by-second.md)在实际提示词中保留数值 BPM、每拍秒数与关键拍—秒—事件映射。BPM 是导演协作目标，不自动要求配乐，也不保证模型逐帧同步。自然表演可松弛服从；静止和连续动作不必每拍变化。
