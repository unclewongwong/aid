# 综艺包装与节目片头：同一套识别，服务每一个现场

用于明确需要综艺/节目包装、栏目片头、环节转场、人名条、花字或节目图形的项目；访谈、竞演、旅行、美食、知识节目和YouTube系列都可按需使用。电影片头可借用标题段落的方法，不默认加综艺花字。仅仅“开头要抓人”不等于需要整套包装，更不等于所有片子自动添加片头、字幕和音效。

沿用[开场吸引力](opening-hooks-and-viewer-promises.md)、[广告包装](ad-packaging-subtitles-and-graphics.md)的阅读层级和[制作放行规则](production-acceptance-and-revision.md)。本页只补充节目识别系统、片头结构与现场元素的选择；不重复建立剧本、时间线或生成流程。

## 1. 先确定节目的性格，再建立一套可复用语法

从用户已给的节目概念、人物关系、内容形式、参考、画幅和声音要求判断：观众是来看竞技压力、轻松陪伴、机智交流、知识发现，还是舞台表演？明确一个主气质及其边界，例如“轻巧机智，但不嘲讽嘉宾”，而不是把热血、治愈、搞怪和科技特效全部混用。

在既有项目视觉契约中补充以下最小信息，能从素材得出的不重复问用户；节目正式名称、嘉宾身份、品牌资产、规则和比分不能猜。只有缺项实质影响结果时才集中询问，不强制新建品牌文件或逐项审批：

- **一个节目母题**：来自内容的可辨形状、物件、空间或动作关系，贯穿片头、条板与转场；不是随手选一种粒子特效。
- **识别与信息分层**：节目字标/主标题、环节名、人物名与身份、规则/数据、编辑评论各有职责；共享色彩、字形和形状语法，但阅读权重不同。
- **运动性格**：哪些元素滑入、展开、逐步显露或轻弹，怎样停稳、退出；弹性与错位可用于轻松表达，克制擦除/淡化可用于访谈。不要把所有卡片都做成弹簧。
- **资产和变化范围**：实际Logo、可用字体、色彩、纹理、原创/获授权声音；哪些是全季固定，哪些随集数、嘉宾、主题更新。用户正式资产优先，不从压缩截图臆定精确品牌色。

先让片头、人物条和一个环节卡看起来来自同一节目，再扩展需要的元素。保持的是识别系统，不是每个画面都塞同一个Logo。已有20种视觉预设可提供媒介方向，但仍需本节目的识别规则；不要新增一套与全片冲突的默认综艺画风。

## 2. 包装元素菜单：按任务取用，不全套堆满

把包装分成**节目识别、结构导航、现场表达**三层。每个元素都写明它新增什么信息或情绪；没有作用就省略。以下名称是创作分类，不是Partner的新API参数或已内置的素材模板。

| 元素 | 适用目的与触发 | 关键边界 |
| --- | --- | --- |
| 主片头/节目字标揭示 | 建立节目世界、气质和名称，进入独立单集时按需要使用。 | 有微型变化过程，最终标题清楚；不能让观众先等一段无关炫技。 |
| 短标识/短过门 | 冷开场后亮出节目名，或同一节目较短的发布版建立识别。 | 从主系统提炼一个动作与落点，不等于把长片头整体快放。 |
| 环节标题/转场板 | 任务、地点、时间或主题实际改变时告诉观众“进入哪里”。 | 区分真实换场与同场切镜；不要每个镜头/生成段都插转场。 |
| 人名条/嘉宾卡 | 人物首次需要被识别，或离场较久后重新进入。 | 姓名、身份有依据；给完整阅读窗口，不遮脸、手和正在展示的物件。 |
| 任务卡/规则板 | 建立本轮目标、限制、胜负判断及必要例外。 | 把理解现场所需的规则先讲清，复杂规则分层；不能临到结果才偷偷改规则。 |
| 计分/进度/倒计时 | 帮观众追踪有真实依据的比赛或任务状态。 | 数值对应实际事件，更新顺序一致；剪辑省略不冒充连续实时时钟，不造压力。 |
| 花字/强调字/编辑短评 | 强化一个已经发生的反差、犹豫、误会或可见反应。 | 不逐句复印对白，不泄露未发生的包袱，不把推测写成嘉宾真实内心独白。 |
| 箭头/圈注/贴纸/抠像 | 指向易错过的动作、物件或关系，适量强化现场趣味。 | 指向明确、及时退出；跟人/跟物与固定屏幕位置分清，不拿贴纸遮关键证据。 |
| 定格/回放/分屏 | 重看关键瞬间、比较过程，或展示有依据的同时反应。 | 标明回放/时间差；不同时间的反应不能伪装成同一时刻，不能把重播当新事件。 |
| 角标/片尾/下集预告 | 持续低干扰识别、收束成果，或给下一集真实期待。 | 非必选；预告不虚构情节，赞助/鸣谢/CTA只按真实资产与本次目标加入。 |

先保证无装饰的现场本身可理解，再决定哪里需要图形帮一把。赛事可重状态、旅行可重地点和观察、谈话可重人物关系；不能因为“综艺感”就让任何类型都满屏花字。

## 3. 片头是一个小段落，不是等待正文的门槛

先选入口结构，服从已锁定的首镜、顺序和片头，不默认挪动现成素材：

- **现场冷开场→短标识→继续现场**：先给本集真实看点，标识后接住同一问题并补充新信息，不重播一遍开头。
- **标题融入第一段行动**：人物、物件、空间或图形变化自然揭示标题，片名出现的同时故事仍在推进；文字可读优先于复杂遮挡。
- **完整独立片头→正文**：适合用户明确需要栏目仪式、系列识别或独立片头交付时；开头本身也要有具体观看价值。长短由目的和阅读时间决定，不固定8秒、15秒或镜头数。

片头内部可用“内容母题出现→发生与节目有关的变化/汇合→准确节目字标落定→通向首个内容镜头”的微型结构，按项目删减或重排。2D字体、拼贴、手绘、实拍空间或3D场景都能承担，不默认做雨夜霓虹、粒子爆炸或相机绕字旋转。

具体写清：最先看到什么；哪些形状/物件怎样变化；观众何时认出主题；最终名称怎样完整可读；从哪个位置、动作、形状或声音进入正文。场景里的字标要有合理空间、遮挡和镜头路径；3D厚度、反射、光效和透视不能让中文笔画糊成一团。节目名、期数、嘉宾和口号分先后阅读，不在最后瞬间同时出现。

一套节目可以需要主片头、短标识和环节过门，但只交付本次需要的变体。它们共享母题与字标，分别重写节奏；不要求每个版本完整播放同一片头，也不在每个API生成段重复开场。无声作品仍可成立，音效或音乐不是强制条件。

## 4. 花字与喜剧节拍：跟着事件走，不替人物演戏

先定位现场事件和观众知情顺序，再决定图形介入。常用判断是“看见动作/反差→观众认出来→必要时用短评点一下→退出让现场继续”，不是固定延迟帧数。包袱要靠反应成立时给表演留空间；必须靠圈注才能发现的小细节，也可以先指向证据再等待结果。

- 一次突出一个主焦点。规则卡、比分变化、花字和音效不要在同一时刻争抢；次要装饰可减弱或后移。
- 评论来自已经可见的行为和节目语气，不凭空代入“他嫉妒了”“她肯定讨厌他”等真实心理判断；戏谑标签也不能伪装为人物说过的话。纪实、痛苦或严肃内容不强行搞笑，不靠羞辱身体、身份或脆弱处境制造效果。
- 先写短而具体的评论，再选表现法；箭头、短暂停留、构图对比有时比大字更有效。流行梗和谐音依赖受众语境，不假定跨语言都能懂。
- **对白/旁白字幕仍默认关闭。**明确要求花字，只授权相应编辑性图形，不自动授权全程字幕；不能把整句台词换个字体就称为包装。“不要字幕”时不以花字复述话语绕开限制；“不要屏幕文字”时同样停用标题/标签，冲突需求先澄清。
- 声音只在用户音轨要求允许且有帮助时加入；可以用轻重、留白与时机区分重要事件，不每次都加夸张音效。声音与具体事件对齐，不盖对白/细微现场声，不默认另生成独立TTS后贴。

笑点组织另见[喜剧导演与节奏](comedy-direction-and-timing.md)。包装能强调关系，不能挽救不存在的因果或靠虚构现场补笑点。

## 5. 落到已有时间线：事件、阅读、进出与复用

在既有分镜/逐秒稿中为需要的元素加一条说明即可，不让用户另填包装表：

```text
所属镜头与触发事件 → 元素及作用 → 确切文案/资产与事实来源
→ 屏幕位置或跟随对象 → 入场方式 → 完整可读的保持 → 退出条件
→ 声音（若需要）→ 下一镜是否保留/如何更新
```

这是一条文字制作约定，不是新的工具字段。导演稿可相对真实事件标记时机；剪辑时才把实际事件落到主时间轴，不能把模型目标秒数当作生成结果已经精确命中。

- **入场、可读保持、退场分别规划。**阅读从完整内容清楚出现后算起；长人名、双语、规则和多位数需要相应空间/时间。时间不够先减字、拆层或少用元素，不靠快速闪完。
- **版式应对真实内容。**用本项目最长标题、人名和实际最大数值检查换行/溢出；为横竖画幅分别布局，结合已知平台遮挡和人物运动预留位置，不把统一边距百分比冒充所有平台规范。
- **进出有因，主次有别。**预备动作、缓动、错峰和余势是可选工具；计时器匀速、机械运动线性或刻意硬切都可能正确，不迁入“所有动画禁用线性”的绝对规则。一次主要变化要有可辨起态与落点，淡化也可以是合适的处理。
- **状态跨镜连续。**人名条在同场切镜时按需要延续或退出；比分只在真实得分时变，队伍颜色/名称不互换；每集复用固定系统、替换当集事实，不把上一集文案留下。
- **时间只有一份基准。**仍以标准速度主时间线编排。若按现行规则做最终整体1.2倍，包装/声音也明确进入同一映射，并预留最终可读时间；不能包装先变速、成片再变一次，或靠加速片头补救信息过载。

## 6. 生成与后期分工，不把方法冒充客户端功能

视频模型适合生成节目世界、材质、空间、人物行动及整体氛围；准确字标、姓名、规则、比分、倒计时和必须踩准的图形进出优先使用可控图形/剪辑层。若用户只要求方案，就写到方案为止；新的生成、素材制作和工具安装仍须服从原授权。

制作前核对实际能力。`aid_compose`的拼接能力不自动等于可叠字、抠像、跟踪或渲染3D；只用已存在且可验证的本地处理/工作流，不凭本指南新增虚构参数，也不自动安装外部Skill、AE、Remotion、Three.js或导出引擎。缺能力时说明具体缺口与可行的简化方案。

需要代码图形时沿用[解释动画与艺术动态](explainer-and-art-animation.md)：同一时间得到同一画面，资源和字体就绪后渲染，跟随图形统一对象/屏幕坐标。循环、单次播放和结尾保持是不同用途，按所需模式实现；片头不用强制循环。跟随人物的贴纸若无可靠跟踪，就选择固定屏幕注释或简化设计，不能声称已准确贴附。

透明叠加层只在确有复用/合成需求时交付，明确尺寸、帧率、时长、锚点、透明/预乘方式及宿主支持的格式；按实际文件核验Alpha，棋盘格图案不是透明，也不能默认普通H.264 MP4带透明。字体、音乐、贴纸和节目标识需有使用来源；公开案例可学方法，不等于其中Logo、明星肖像、音效与模板可直接挪用。

文字方案完成时做轻量复核：是否一套识别、每项是否有信息任务、名称/规则/分数是否有依据、片头是否接住开场、花字是否提前泄底、阅读与遮挡是否合理、是否越过声音/字幕/工具权限。实际制作的文件、时间和定点检查按主Skill制作放行规则，不新增默认全片抽帧、审美评分或付费重做；未渲染就只报告方案已完善。

## 7. 原创微例：同一母题怎样变成一套包装

以下只演示方法，不是新节目任务、默认模板或已生成样片：

- **轻松旅行栏目，母题“路线与到达”**：片头由沿途片段中的路径衔接到节目名；人物条沿用同一种折线边框；地点切换用路径延伸；现场迷路若确有素材，可用一次指路箭头和简短编辑评论。地图路线须真实或明确示意，不用随机坐标伪造旅行。
- **协作烹饪节目，母题“分工与合盘”**：片头由不同任务区域汇合成一桌/标题构图；角色条区分分工而非随意给性格定论；任务卡说明真实限制；成菜后更新结果，不预先显示不存在的成绩。面粉、热气等可成为统一转场形态，不复制某档节目的专属形象。
- **访谈/知识节目，母题“一个问题被展开”**：片头用简洁纸面/线条展开题目与名称；章节卡延用层叠关系；人名条克制，关键观点优先交给说话者和证据。无需笑声音轨、弹跳大字或竞赛倒计时，也不自动加对白字幕。
