# 摄影真实感：把参考质感写成可执行提示词

用于用户要求真人实拍感、自然皮肤、胶片感、镜头感，提供摄影质感参考，或反馈图片蜡、油、硬、像渲染时。与[GPT-Image 静态图](gpt-image-still-prompt-design.md)、[电影视觉契约](cinematic-visual-direction.md)配合使用；不覆盖用户指定的动画、插画、手机或其他媒介，不新增模型、API 参数或生成任务。

本方法来自用户2026-10-19至20提供的18张可见参考图像，覆盖自然光人像、柔光美妆、直闪、街拍、古风、多人、镜面、薄纱、幻想大场景，以及重新上传的雪山针织背影。用户明确这些图来自Midjourney，而非实拍照片；不能断言真实相机、焦段、胶片、EXIF或LUT。用户随后提供的MJ提示词另见[MJ→GPT迁移](midjourney-to-gpt-image-prompts.md)。学习是整理可迁移的编写方法，不是训练、微调或向模型永久注入这些图片。新增配方须与实际生成验证分开记录，不把一张测试图的结果推广到全部场景。用户图片留在授权制作资料中，不随可发布Skill复制分发。

## 1. 先明确审美方向，再找支撑它的成像条件

写清当前作品是浪漫电影、干净美妆、复古抓拍、古典舞或其他方向。自然与美感可以并存：精致不等于塑料，真实不等于粗糙、暗沉或取消人物吸引力。`dreamy`、`beautiful`、`cinematic`可作为审美起点，不必全部删除；用表情、光块、色彩和材料把它们落地，不能只剩一串缺陷禁令或微观皮肤要求。

真实感的核心是同一画面中的因果相容：光从哪里来，表面怎样回应，人处于什么状态，相机站在哪里，焦点选择什么，以及高光和阴影怎样被记录。`live-action film still, real performer on a practical set`可以表达媒介意图，但不能代替这些可见条件。这里说的是成片中可信的现场质感，不是要求把剧组、摄影机和灯架拍进画面。

先提取一份短“摄影条件卡”，再编译成自然语言，不把字段冒充API参数：

- **内容与观看目标**：身份、动作瞬间、情绪线索、要看清的物件；已有身份与故事不因风格参考而改变。
- **主光与环境**：位置、软硬、颜色、照亮范围；环境反射或辅光的作用。暗面保留多少由现场与情绪决定。
- **机位与空间**：高度、距离、朝向、主体占比，前中后景各承担什么信息。
- **焦点与质地**：焦内重点、焦外衰减，皮肤/布料/金属/透明物各自可见的反应。
- **成像与色彩**：肤色、中间调、高光、黑位、饱和度；是否需要颗粒、轻微光晕或动态痕迹及其程度。

例如“左侧窗光塑出脸的转面，眼睛清楚，耳后和旧木墙逐渐柔化；脸颊大面哑光，嘴唇有小面积反光”比“8K、超写实、极致毛孔、cinematic”更明确。清晰度参数决定交付尺寸，不证明摄影真实感。

## 2. 按场景选主配方，不把参考揉成一个滤镜

选最匹配的一项光线/成像配方；构图模块可以另选。混合光只有在能说清不同光源各照到哪里时才组合，不能在同一面部同时要求均匀柔光、直闪平面照明和强侧向硬影。

| 主配方与适用情景 | 写进提示词的可见证据 | 不自动继承的参考内容 |
| --- | --- | --- |
| 方向性柔窗光／环境人像 | 大窗从一侧柔和塑形，亮面向暗面渐变，环境有弱反射，眼神光与窗位对应，背景安静但仍可辨地点 | 暗绿调、特定长发、白裙、旧家具或悲伤表情 |
| 自然逆光／花园与林间 | 太阳给发束与衣缘亮边，脸接受天空或地面反光；前景植物遮挡少量画面，环境与人物共享光向 | 必须金色夕阳、全脸发光、遍布尘粒、所有背景虚成色块 |
| 硬日光／有风的户外 | 明确鼻影和发丝投影，天空与暖色衣料分离，头发和衣摆同向受风，亮部仍有材料区别 | 默认浅景深、统一雾化、夸张飞发或所有人物闭眼 |
| 山野环境／背影与动作 | 松弛的肩臂与重心，针织有重量和拉伸褶皱，头发受风方向一致，暖草与冷山分离；前景柔化但山体轮廓可辨 | 必须展示脸、过度虚化成无地点色块、对称摆臂、针织全域一样锐 |
| 干净柔光／美妆近景 | 大面积柔和受光、自然肤色渐变、稳定眼神光、细微皮肤起伏，唇部光泽与哑光皮肤区分 | 磨皮瓷面、强制雀斑、加皱纹、把人物变年轻或改脸型 |
| 近轴闪光／近距离抓拍 | 正面较直接受光、局部高光清楚、背景相对退后，首饰与皮肤的反光不同 | “直闪=湿脸”；汗、水、油光只在人物状态需要时写，并限定位置 |
| 柔和胶片街拍／途中一瞬 | 行走姿态和头发有惯性，主体仍可读，背景街道有地点证据，微反差柔和、细颗粒克制 | 全图模糊、故意脏旧、泛黄、每张都要看镜头摆拍 |
| 暖实景灯／室内材质 | 灯罩或窗外提供可解释暖光，皮肤、金属、绒毛与玻璃各自响应，环境冷暖有主次 | 到处添加灯、青橙对撞、把布料和皮肤都做成金属反光 |
| 低调侧逆光／薄纱与亲密近景 | 暗面有重量，受光轮廓清楚，薄纱透射与重叠变暗可读，脸部重点而非整张图提亮 | 黑位一律抬灰、全图烟雾、湿皮肤、必需亲密动作 |
| 大场景／可信幻想 | 人物、建筑、巨物共享透视与光向；金属有局部强反射，皮肤较柔和，薄布有重量与透射；空气粒子受光且前后疏密不同 | 删除故事中的幻想设定；反过来也不能因幻想而让全部物体无重量、无尺度、自发光 |

**空间模块按需叠加**：

- 前景遮挡服务于观察位置或景深，例如虚化器物、树干或布料给出距相机更近的平面；不为了“镜头感”挡住要读的眼睛或线索。
- 镜面构图明确相机、人物与镜面的位置；实身与倒影是同一个人、同一姿态与服装，不增加第二个人。允许对焦倒影而让实身前景柔化；反射角和可见范围须相容。
- 多人构图保持同一地面、相对尺度、视线目标与统一光源。低机位和大块天空可加强群像关系，但不是所有人物图的默认。
- 双人近景先定各自朝向、距离和眼神交点，再定焦点、局部遮挡和背光；不把“亲密”写成两张无空间关系的脸贴在一起。

## 3. 质感分配：真实不等于粗糙

**皮肤**：保留原人物的年龄、五官与识别特征。以自然肤色变化、明暗转面和局部反射表现真实；干净平滑的皮肤也有体积。不要为“反AI”给所有人加雀斑、皱纹、病态暗沉或粗毛孔，也不要为了“美”换掉原脸。脸颊可哑光，鼻尖或嘴唇可有小面积高光；湿润额头的闪亮属于特定身体状态，不能扩展成整张脸、所有角色的默认油膜。

**尺度与焦点**：远景读轮廓和色块，近景读表情和少量纹理，特写才显露更细微的细节。焦内和焦外不能同样锐，毛孔不能成为覆盖皮肤的均匀网格；推近不等于每格增加锐化或粗糙度。眼睛常是人物近景重点，但道具或关系信息需要被看见时不机械锁眼。景深只抑制无关信息，不抹掉故事证据。

**头发与衣物**：发束的重量、少量离散发丝、投影与光泽有区别；不要每根头发都发光。棉麻、针织、绒毛、丝绸、金属与薄纱分别描述织纹、折痕、软硬、反射或透射；纹理随透视缩放，褶皱由重力、姿势和接触产生。

**镜头感**：先写相机与主体的距离、视点和焦平面。需要时才用焦段、光圈等作为创作目标；不能从参考照片反推出“必定85mm f/1.4”。透视由相机位置决定，焦段配合取景，不用互相矛盾的器材名词堆出高级感。适度光学柔化不等于整脸磨皮；运动模糊须有真实运动方向和清楚的阅读重点。

**胶片感**：优先处理高光柔和收敛、肤色与环境分离、中间调层次及有重量的暗部，再决定是否加入细而克制的颗粒。颗粒是成像纹理，尘埃是场景物件，不能混用；亮反光边缘的轻微光晕也不是全图白雾。胶片感不强制暖黄、绿色阴影、低饱和或颗粒可见，阳光蓝天和干净肤色同样成立。不宣称提取了原胶片曲线、原LUT或精确复刻器材。

## 4. 导演、视觉预设、摄影条件分别负责什么

三者共同进入当前图像的**实际prompt**，不是只写在项目故事、风格标签或聊天里：

1. 导演方向负责观看位置、构图关系、表演分寸、信息何时显露；从[导演索引](directors/index.md)读取被选项，把名字翻译成当前画面的可见选择。不要把导演名字当万能滤镜。
2. 视觉预设负责记录媒介、造型与色彩起点。10号写实电影的暖金／橄榄配方是特定预设，不是所有真实摄影的定义；当前用户参考、人物与已锁定场景优先，不擅自覆盖该预设或另改其他19项。
3. 摄影条件负责这一场实际受光、空间、焦点、材料与成像。导演的克制几何构图可以与自然柔窗光共存，无须一律压暗染绿；幻想内容也可拥有可信的实拍材料响应。

发生冲突先解释和取舍，例如“保留既定机位与人物，只参考新图的肤色过渡和焦外”，不同时塞进互相抵消的要求。用户明确要求复刻某一配方时优先其指定，而不是自动改成自然纪录风。

## 5. 参考图职责与提示词编译

先检查所选服务实际支持的多图模式及输入顺序。最少的充分参考通常比一包不同人脸更可控：使用已有身份／目标图，另选与本场光线相容的质感参考；没有必要时只用文字。不强制参考张数、不额外生成角色图、不把所有样片一并上传。实际参与生成的用户素材只走已授权服务。

明确“图1锁定身份、衣服、场景；图2只参考受光、肤色过渡和焦外，不继承其脸、发型和背景”。图号必须对应本次真实请求。参考职责是创作约束，不保证模型能完全解耦属性；返图仍需检查混脸、发型或服装漂移。仅看过、记录路径或写在项目references里，没有实际传入请求，不算模型已看到。

如果旧目标图本身具有不想要的皮肤或成像特征，强约束其全图可能仍保留这些特征。允许换构图的方向探索可用一次纯文字样稿观察提示词；必须锁脸的任务仍保留身份参考。两者不能冒充严格单变量对比，详见[MJ迁移的参考策略](midjourney-to-gpt-image-prompts.md)。

静态提示词可按以下骨架写成一段连贯指令；中英文均可，按当前模型实际能力选择，不声称某语言必然更好：

> [实际参考职责与必须保留的身份/场景]。[审美方向与媒介]中，[主体]正处于[一个可见瞬间]。[机位、景别、人物位置与前后景信息]。[主光方向/软硬、环境反射及受光范围]。[焦点及自然衰减]。[少数重点材料的不同响应]。[肤色、明暗过渡与适度成像特点]。[针对本图的少数必要限制]。

按需要展开，不要求把每个槽位都写满；无关的器材、身份细节和禁令删掉。

### 示例：柔窗光中的人物近景

> 保留角色图中的成年人物、短发、深红围巾和旧候车室。真人实景剧情片中的一个瞬间：她听见站台方向的声音，目光刚抬起，嘴唇轻轻松开，仍未转头。相机平视从胸口以上取景，左侧旧窗框保留少量空间。窗外象牙白漫射日光从左侧塑形，室内反光轻托暗面；肤色自然，中间调可读，背景灰绿而不染绿脸部。眼睛清楚，耳后与远处墙面逐渐柔化。脸颊大面哑光，鼻与唇只有局部微光；棉布与围巾保留不同织纹。高光平顺，颗粒细而轻，不增加粗毛孔、年龄纹理或湿脸效果。

### 示例：硬光与风，不套柔雾

> 户外低机位半身人像。人物刚转向侧前方，风把几束头发从左向右带起，手仍压着外套下摆。午后日光从右上方照来，鼻梁和发束在脸上留下方向一致的清楚投影，蓝天占上半画面；橘棕外套与天空分离，面部保留自然明暗，不做均匀柔光。焦点落在靠近相机的眼睛，衣料褶皱有重量，亮发丝只出现在受光边缘。干净摄影成像，不加全场烟雾或统一黄滤镜。

### 示例：镜面组织空间，不增加一个人

> 同一位成年人物站在旧立镜前，实身背部占左侧近景，镜内的脸在右侧中景看向自己的眼睛。镜中发饰、领口和抬手姿态与实身一致，反射范围符合相机站在人物左后方的位置。右侧窗光同时解释肩部与倒影里的受光，焦点落在镜内眼睛，近景肩饰柔化。丝绸有柔亮折痕，旧木镜框是较暗的磨损哑光，金属小饰物只有局部亮点。肤色不因暗背景而发灰，不增加第二位人物或摄影机倒影。

以上为编写示范，不代表这些情景均已实测。

## 6. 四宫格与视频：同一个摄影世界

是否采用四宫格仍由[镜头复杂度与用户选择](four-panel-motion-storyboards.md)决定，本模块不把简单定镜变成强制四格。选用后沿用4K整板默认及真实尺寸检查，不为本模块另生成四次图片。

一次连续镜头的四格共享身份、服装、光源位置、色温、材料和成像基线；每格分别写一个可见状态，视线与反应有因果，摄影机从起点逐渐到落点。不要只有四次无关摆拍，也不要一格街拍、下一格直闪、最后突然美妆棚拍。景别变近允许焦外和细节尺度自然变化；不通过新增皱纹、锐化或改变脸型表达推进。只有真实跨入新光区等剧情变化才改变受光，并写清过渡依据。

特写取景具体到“两个眼睛、眉毛和鼻梁上段可见，嘴和鼻尖在画外”，不要既要求眼部特写又要求整脸与全身。静态整板只证明计划画面，不能据此宣称视频运镜或身份连续已验证。裁图、实际素材绑定及视频三段连续过程仍按四宫格指南执行；用户只要看整板时不擅自启动视频或其他付费生成。

## 7. 有限检查与结果报告

提交前核对选定的主配方是否相容，参考是否真实传入，导演／预设／摄影条件是否进入正文，API尺寸是否真实生效。返图按授权范围做一次可见检查：

- 身份、人数、服装和故事状态是否保持；是否借“真实”偷偷改了年龄或种族外观。
- 人物和环境是否共享光源、尺度与空间；眼神光、反射和材质响应有无明显矛盾。
- 肤色转面、焦点、焦外和微纹理是否有层次；有无蜡面、全脸湿亮、蚀刻毛孔或均匀噪点。
- 四格是否连续，景别与状态是否确实变化；实际整板像素与单格像素分别报告。

说明改善与不足，不自动评分、不循环付费重生，不以“高清”“参考学习完成”代替查看真实文件。若比较时同时改变了提示词、参考输入或模型，应称方向测试，不称严格单变量A/B。链接无法读取时明确标记未见，不推测其画面。用户要迭代时再针对实际不足改下一轮。
