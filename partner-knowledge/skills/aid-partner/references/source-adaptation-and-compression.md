# 长原著改编：可追溯地取舍，不把因果压没

用于用户要求把小说、长故事、多集散稿或已有叙事材料改成剧本/短剧。只分析就交分析，只改编约定范围；原创、普通Vlog、科普资料整理和已定剧本直接执行分镜，不必经过本分支。沿用[故事先行与跨集连续](story-first-and-series-continuity.md)的总纲、正文和记录，不建立第二套项目状态或新命令。

## 1. 先确认材料与允许改变的范围

从已有需求提取：原文/版本、当前交付范围、目标片型与时长、必须保留的人物立场/关系/关键选择/结局，以及允许压缩、重排或新增的范围。信息足够就继续；真正影响改编方向的冲突才问，不逐章审批。

没有原文就明确缺少材料；可做方向讨论，但不凭书名、梗概或记忆声称已分析原著。用户只给前几章时，只对已读范围下结论，结局和后续依赖标待核。允许自由改编不等于已授权生成、公开材料或替换已有作品。

## 2. 长材料先建立可找回的阅读记录

先辨认章节、场景、时间跳转、叙述视角，再提取当前任务需要的事件。简单短材料直接分析，长材料可分批；记录实际覆盖和待读部分，不用抽样冒充通读。

沿现有剧本目录/项目story保存精简映射，字段按需要合并：

```text
来源文件与版本；已读/抽样/待读范围
定位：章/场景/页或行区间（实际可得的定位，不编页码）
事件：先前条件 → 谁采取什么行动 → 结果
作用：建立/兑现什么，谁因此知道/获得/失去什么
处理：保留 / 压缩 / 合并 / 换呈现 / 重排 / 删除 / 待定
去向：本次大纲或集/场景；被保留、转移或失去的功能
```

来源事实、Agent推断、改编决定分开写；称谓可能同人、时间矛盾或证物归属不明时保留歧义，不先写成正式人物库。默认存摘要和定位，原始文件留在用户指定位置；整书不塞入生成prompt或公共知识包。

有检索工具时，用“人物＋地点/物件＋当前行动”的事件组合查找，再回读命中上下文。检查这段所属的故事阶段：后期已取得的证据、技能、盟友或知情，不能顺手移到前集。源文件修改后重新核对受影响定位；没有索引器时用可用阅读/搜索工具，不声称Partner已有自动章节索引或跨文档校验。

## 3. 压缩按戏剧功能取舍，不按字数均分

先判断哪些情节服务本次观看承诺，再查准备删除的支线是否仍为保留部分提供条件：

- 主角行动所需的证据、资源、权限、技能或盟友从哪里来？
- 谁的信任、关系、误信、承诺或代价在这里形成？
- 哪个铺垫要在后文兑现，哪个结果又是别处铺垫的兑现？
- 删除后是否改变观众与人物的知情差，或抹掉必须现在行动的理由？

功能无须保留时可一起删去，并清理失去去向的铺垫；功能仍被依赖时，要指出由哪个已保留的行动承接，不能只写“合并到主线”。不以固定删减比例、角色数、场次数证明改编成功；原文的慢段也可能承担快段成立的条件。

合并人物再核对目标、立场、关系历史、知情与行动是否能由同一人自洽承担。两人一人持秘密、一人负责追问，合并后可能使追问失去理由；同一时刻两地的行动也不能无交代地合一。角色少不自动代表更好拍。

## 4. 高光提前，要同时搬动它成立的条件

开头抓人优先从本次内容找真实冲突、异常、选择或情感证据，方法沿[开场吸引力](opening-hooks-and-viewer-promises.md)。若获准采用后段高光作冷开场或重排：

1. 记录原位置、新位置与本次允许改变的内容。
2. 核对事件所需的证据、人物关系、能力与代价是否已成立；需要补的因果桥写进正文，不只写在说明里。
3. 让观众读懂叙述时间；回到原位置时说明是完整展开、补另一视点还是已移除，避免重复兑现或假装没发生。
4. 更新受影响的总纲、分集入口与连续性记录；不能借“更勾人”暗改锁定人物、对白或结局。

## 5. 内心与说明改成屏幕事件

保留“观众必须明白什么”，再选承载方式：具体选择及代价、人与人之间的反应、可读的物证、环境后果，或本片已允许的对白/旁白。没有旁白时不能擅加旁白；依赖屏幕细字时先考虑真实可读性和制作能力，不把关键因果押在不可辨文字上。

区分编剧知道和观众实际获得。写在人物设定里的牺牲、藏在资料里的证据、留到未拍支线的动机，都不算已经表达；关键功能要定位到正文中的可见/可听事件，再交给导演选择镜头。

## 6. 分集依据局部结果和准确交接

章数不等于集数，字数不等于屏幕时长。按本次片长和片型，选择一段能让目标、行动与结果被读懂的事件范围；本集兑现哪项期待、留下什么后果，沿已有分集表记录。一个章节可拆、多章可合，不为了集数在答案前机械切断。

尚未读到的后续不能编成原著事实；后续已知但当前集不该知道的内容不能泄漏给角色。系列正文分批展开时，当前采用版本和实际退出状态回写到原连续性记录，不另存互相冲突的“真相”。商业连载需要的压力与回报再读[商业连载技法](commercial-serial-drama-craft.md)，并非所有改编都要爽剧化。

## 7. 示例：少一个人，不能凭空多出一把钥匙

假设原材料中，保管员因主角曾替他担责，才交出资料室钥匙；主角随后取得关键账本。若为压缩角色删除保管员，不能直接写主角进入锁着的资料室。可在允许改编的范围内，让已存在且合理持钥匙的人通过一个具体选择交钥匙，同时保留这次信任的理由与代价；若该人物立场不容许这样做，就换方案或保留原功能载体。

这只是方法示例，不是强制增加钥匙、账本或担责情节。交付时指出实际删改及受影响范围；不将改编表当完整正文，也不据此宣称样片已通过。
