# 广告片包装、字幕与图形叙事

用于广告、品牌短片、产品介绍、片中片、社媒发布版，以及需要字幕、标题卡、产品界面、角标或片尾 CTA 的剪辑设计。图形不是成片完成后才贴上的装饰层：它参与观众先看见什么、理解什么、何时相信产品，以及最终采取什么行动。

**字幕默认关闭。只有用户明确提出需要字幕时，才制作、生成或烧录对白/旁白字幕。**视频中有对白、用户要求视频包装、短视频发布或平台常见做法，都不构成加字幕的授权。标题卡、叙事性屏幕文案、剧情内可见文字、产品界面标签、Logo 和 CTA 不是对白字幕；它们也不能被用来绕开用户的“不要字幕”要求，必须各自符合用户需求、故事证据或品牌目标。若用户没提字幕，就不主动添加、不在交付里默认提供字幕文件。

## 广告先定创意路线：产品感官片不是功能演示片

用户只说“做个广告片”时，先从产品/品牌与已给素材判断观众究竟要**想吃/想摸/想拥有**、要**理解功能**、要**相信一个故事主张**，还是要**记住品牌形象**；可组合，但每支短片选一个主承诺。下方软件功能的“问题→输入→结果→行动”只适用于需要证明流程的产品，不强迫食品、香氛、时尚等感官广告虚构用户痛点或戏剧反转。普通未指定的风格可提出创意判断；产品版本、真实卖点、包装字标和禁用主张须由用户素材或已核验资料支撑，不猜口味、成分、功效和品牌标语。

产品感官片先写一句**购买欲望/感受承诺**，再选择最少的可见证据与声音：可辨认的产品与包装 → 期待动作（拿起、拆封、切开等）→ 关键材质事件（裂开、流动、起泡、拉丝等）→ 人的感受或使用结果 → 产品/品牌收束。它是可重排、可删减的感官因果链，不是固定五镜模板；无人物也可由材料变化和声画节奏兑现。每镜说明观众新看清的产品事实，避免“不同景别的同一件东西”重复占时。质感写具体接触、形变与恢复：哪一层在何处受力、裂纹/碎屑/液体沿什么方向与速度变化、何时停住，匹配材质厚薄、光泽、温度、重力与同期声；“8K、电影感、超真实、令人垂涎”不能替代这些可观察事件。声音可让拆封摩擦、脆裂、流动、咀嚼或环境成为节拍；音乐只在声源和节奏不抢关键产品声音时加入。

短广告按**真实动作容量和品牌阅读时间**分配镜头。逐镜列开始状态、动作、结束状态、景别、切点与声音；拆封、咬开、断面显露、融化、人物反应各需足以看清的时间，不能因九宫格有九格就把10秒硬切成九个一秒镜头。时长紧时减少事件/镜头，或在用户允许下延长广告；不要靠模型一次生成去赌准确九切。已咬开的产品、融化中的产品与片尾完好英雄包装要区分**同一件产品的连续状态**还是**另取一件展示样品/有意省略时间**，不能让同一物件无因复原。片尾 Logo、准确包装字和口号需要稳定阅读窗口及可控图形层；只有已确认的品牌资产/文案才进入最终画面，不把九宫格上的演示文字当成品牌正式文案。

产品正反面图分别控制外形、包装结构、配色、标识和可见文字；它们不自动证明内部断面、口味或受力物理。若做九宫格，先把每格的产品状态、材质事件、景别与作用写成镜号映射，再区分**供人审阅的带标题/时间码展示页**与**供视频模型引用的干净画面板或裁切单格**；展示页的卡片、编号、页眉页脚不能进入成片。整板参考是否可用、单格像素是否足够、模型是否支持多图/多镜，以实际路线核对；只读到一张整板不等于模型会正确依次执行九镜。精确切点、碎裂形状、飞散物轨迹、音乐同步和品牌文字若是交付硬要求，留给有相应能力的独立镜头与后期，不承诺单段生成全部准确。

迁移依据：用户2026-09-30提供的雪糕广告两阶段提示词。吸收“产品多角度参考→多景别感官递进→品牌收口”的方法，不复制其品牌、九镜顺序、10秒长度、黄金时刻、具体口味、装饰符号或音乐；未取得该示例的实际九宫格/视频，因此不把其效果写成已验证。

## 1. 先画信息轨道，再剪镜头

在时间线上区分以下文字/图形职责，不把它们统称为“字幕”。先应用“字幕默认关闭”规则；只有用户明确要求字幕时才启用第一轨：

| 轨道 | 回答的问题 | 设计约束 |
| --- | --- | --- |
| 对白字幕 | 此刻人物具体说了什么？ | 忠实逐字、跟随实际语音进出；优先一至两行，断句按语义；不能遮住正在表演的眼睛、手、关键道具或屏幕内容。 |
| 叙事标题/屏幕文案 | 观众此刻应带走哪条关键信息？ | 每次只突出一个观看承诺、冲突、证据或转折；允许成为画面的主视觉，但不能复述同屏对白。 |
| 产品界面/流程图形 | 产品实际上做了什么？ | 展示能证明主张的具体步骤和状态变化；使用可读的真界面或有意设计的拟真界面，不用堆满小字的静态“功能墙”。 |
| 品牌识别/CTA | 谁提供产品，观众下一步做什么？ | 标识持续但克制；CTA 在价值已经被证明后出现，写成明确动作并给足阅读时间。 |

每段只保留一个主阅读焦点。字幕和标题争同一位置或重复传达同一句话时，重排时间、位置或删掉其一。人物正在做重要动作时，不让大标题盖住动作证据；产品画面正在解释流程时，避免再叠一段无关宣传语。

## 2. 把包装纳入故事弧

先确定每个段落改变观众的什么认知，再决定是否需要图形：

1. **钩子**：用可见的人物处境、损失、反常点或明确承诺抓住注意；标题强化画面正在发生的事，而不是先介绍品牌。
2. **障碍**：以少量短句或明确视觉符号列出观众真实顾虑；每条顾虑应有后续回应，避免连续播放同义痛点卡。
3. **输入/选择**：若演示“只需几句话”，让观众看见具体输入怎样进入系统；用光标、发送动作、进度反馈等时间变化表现，而非只放空界面。
4. **产品证明**：按照因果展示输入如何变成脚本/素材/视频/交付。重点步骤可高亮，完成与进行状态有明显差异；功能名应和画面证据一一对应。
5. **结果兑现**：用真实生成的作品或可辨认的成片片段证明前面的主张。让界面缩略图、人物/场景信息与成片片段可互相追认；不要把示意图伪装成真实生成结果。
6. **收束与行动**：将品牌识别、核心承诺和 CTA 排成清楚的阅读顺序。结束卡留足稳定阅读时间；不要在最后一瞬同时塞入口号、版本、平台、网址和多个按钮。

段落可按具体故事合并、删减或换序；这不是固定时长模板。每个包装元素都要回答“它让观众新知道/感受到/相信/去做什么？”，答不上来就删或改。

## 3. 建立包装视觉系统

在剪辑前从品牌资产和成片画幅确定一套规则：主/辅助色、字体角色、字号级差、字重、行距、卡片/描边/阴影样式、Logo 版本、角标位置、转场方式、动效速度及字幕安全区。品牌色和 Logo 以用户提供或已核验的正式资产为准；不要从单个案例推导成全局 AID Partner 配色模板。

- 按交付画幅建立安全区。字幕、Logo、平台 UI 和 CTA 都留边距；关键文字避开脸、手、运动路径、亮部噪声和平台常见遮挡区。竖屏、方形、横屏分别重新排版，不可把同一套绝对坐标硬套过去。
- 统一的是排版语法，不是所有文字都长一样：钩子标题可大，说明标签可小，字幕以连续可读为先，CTA 需有明确按钮/动作层级。
- 半透明卡片、局部虚化背景、描边或轻投影仅在底图复杂到影响阅读时使用；对比和字形足够时，不要为了“高级感”叠装饰。
- 角标/水印保持稳定、低干扰且不遮剧情；其出现要有来源/品牌语义。片中片可用简洁来源标签建立媒介边界，避免多套 Logo 重复抢视线。
- 动效要表达输入、进度、完成、转折或视线引导。卡片进场、描边、高亮线、进度条和光标遵循统一节拍/缓动规则，避免每个元素各自飞入。
- 生成模型容易把文字、品牌和界面画错。除非画面中必须由角色真实看见/触碰，否则让视频生成阶段专注画面与表演，后期叠加准确字幕、Logo、UI、数字和 CTA；diegetic text 必须单独列入一致性与可读性验收。

## 4. 字幕写法与时间

用户明确要求字幕后，字幕设计才进入制作计划；以完整语义和观看速度为准，不以固定字数替代判断：

- 口语对白先按自然停顿断行；优先一至两行，避免拆开词组、姓名或数字。超过当前镜头能读完的内容，应压缩口播、延长可读时间或重新剪辑，不能单纯缩小字号。
- 逐字对白字幕不得改写台词。旁白、对白、屏幕文案用不同视觉处理或位置表达，但同一时刻应有一个主焦点。
- 入点不早于观众需要阅读的语句/信息，出点不切断台词、表演反应或下一镜的必要注意力；切镜时字幕是否延续由语义和声源决定，不机械逐镜闪烁。
- 优先选每镜相对稳定的字幕锚点；主体移位或动作占位变化时允许调整，但前后镜需保持阅读习惯。逐帧检查不要撞脸、手、道具、Logo、按钮或界面关键区。
- 字幕必须在目标尺寸与正常播放速度下可读。用实际手机尺寸预览竖屏发布版；在纯色/复杂背景、亮/暗镜头和不同肤色/服装上抽查对比度与边缘清晰度。细描边/柔阴影可提升可读性，但不能依赖模糊重底板掩盖排版问题。
- 关键词着色只用于极少数真正需要强调的词，沿用项目视觉规范且维持整句可读；避免整句逐字跳色/跳动，除非歌曲、节奏或用户明确要求这种风格。

没有对白时，不要为了“有字幕”而把旁白说明塞到画面上。用户没明确要求字幕时，即使有对白也不加对白字幕；可按创作目标设计必要的叙事标题或产品文字，但必须与字幕区分，不能复述对白来变相添加字幕。尽可能让动作、构图、物件和剪辑先承载信息。

## 5. 声画、节奏与包装动效

包装节奏跟随剧情而不是统一的模板 BPM：

- 冲突钩子可以在一至两个节拍内出现，但要给核心文字完整阅读窗口。
- 产品过程用有限的状态变化带观众逐步看清；每次切换最好伴随真实完成状态、输入动作或新证据。
- 情绪片段减少卡片/标签密度，让镜头、音乐和字幕留白承载情绪；不要在每个切点都加转场音效。
- 结尾 CTA 通常需要比短促装饰标签更稳定的停留；音乐、Logo 动效和按钮不要同时抢峰值。
- 如整片采用 BPM/拍点，先标出信息出现、关键词强调、界面完成和 CTA 落点；字幕进出应服从可读性和语音，不为机械踩点而过早消失。

只有用户要求了字幕时，才把字幕计时纳入变速、变调和交付时间轴检查。先完成并锁定声音/画面变速，再核对字幕、口型与音效对齐；或者使用经过验证的非破坏性时间映射。不能只改播放器速度而遗漏已要求的字幕、配音或片尾停留，也不能假定全片加速后人物表演仍自然。

## 6. 代码驱动动效：把确定性留给确定性媒介

用户授权制作包装、信息图、产品演示或精确转场时，可把 HTML/Canvas/SVG/Three.js 等代码动画视为**单独的后期媒介**，不是 H3、Seedance 等视频模型的提示词格式。先完成故事/信息顺序，再决定哪一层用生成画面、哪一层用可重复的代码渲染；不要因为代码能做漂亮动效，就让镜头失去人物目标和前后因果。

- 为每个动效写一条可执行的事件链：**前态 → 可见触发 → 图层/摄影响应 → 新信息或空间到达 → 下一镜接点**。例如产品输入被确认后，发送按钮的圆形轮廓放大为遮罩，直到占满画面才切到生成结果；按钮必须真的先被按下，结果才出现。这样学习的是“物件成为转场入口”的机制，不复制案例的物件或风格。
- 对需要精确控制的层，分别交代画幅、时长/循环、帧率、图层深度、锚点、位移路径、速度曲线、遮罩覆盖时刻、文字内容和导出格式。若有音乐，按当前段落选 BPM 与拍点/小节；既要让图形落拍，也要保留文字可读时间。代码可逐帧算几何，视频生成模型却只能用自然语言近似这种运动；不能许诺同等精度。
- 用景深层/遮挡层建立视差时，先处理原图被前景移开后露出的空洞；用物件或窗口作“入口”时，明确下一场景何时已经在入口内可见，何时入口填满画面并切换。逐帧或关键帧核对边缘、遮挡、拼接和循环接缝，不把“无缝”仅当形容词。
- 精确 Logo、界面状态、数字、短标题与 CTA 由可控图形层完成；是否出现这些文字取决于叙事和用户授权。**歌词或对白的逐字字幕仍遵守本指南顶部的默认关闭规则**，不能因代码动效容易实现就擅自添加。
- 来源分级：完整创作者提示词、片段提示词、转述帖和二次复刻不是同一证据级别。只从可见文本提炼方法，未观看/复现的效果不写成已验证。生成、外部素材、付费服务和发布仍各自需要对应授权。

学习依据：`awesome-opus5-5-videos` [仓库说明](https://github.com/yihui-dev/awesome-opus5-5-videos)将案例定位为代码动画与网页录屏，并说明部分条目只有片段或原帖；[景深门户案例](https://github.com/yihui-dev/awesome-opus5-5-videos/blob/main/prompts/koldo2k-778767.md)提供分层、固定点变焦、物件遮罩、循环与音乐小节的具体约束；[产品徽章案例](https://github.com/yihui-dev/awesome-opus5-5-videos/blob/main/prompts/bthreeagency-827092.md)强调先锁原设计/资产、再追加运动；[音乐短片案例](https://github.com/yihui-dev/awesome-opus5-5-videos/blob/main/prompts/anabology-491441.md)提出生成底片与 JavaScript 图形叠层的分工。它们是创作线索，不是本项目已实跑的 H3 能力证明，也不授权复制原作品。

## 7. 发布前检查

按最终导出而不是剪辑预览做整片回放；至少检查：

1. **仅当用户要求字幕时**，检查台词字幕逐字正确、语义断行自然，出现/消失与实际声音一致；无重复字幕、漏词、残留旧版本和多余生成文字。若用户未要求，检查没有擅自出现对白/旁白字幕。
2. 每一张标题卡、功能名、数字、版本、网址、Logo 和 CTA 拼写/品牌资产正确；屏幕文案没有与旁白/字幕争夺相同信息。
3. 关键帧与运动过程中字幕不遮挡动作、表情、道具证据或重要界面；不同亮度、底色、镜头裁切下仍可读。
4. 包装层没有意外跳位、抖动、错误缩放、溢出安全区或突然改变透明度；角标在允许出现的段落内连续稳定。
5. 观众能按顺序读完“问题→输入→过程→结果→行动”；结尾有足够时间辨认 CTA。
6. 变速/裁切/替换镜头后重新检查整个导出文件的字幕同步、声画关系、平台 UI 遮挡和片尾时长。抽帧不能代替正常速度回放。

## 8. 已完成广告片的经验边界

对 AID Partner 2026-09-26《三句话》广告成片（素材 ID `a5cff360-cd7d-4a4a-88c4-c967298c3302`）的现有画面观察得到：方形 1080×1080、30fps、45.05 秒；包装依次把人物钩子、三条痛点、Agent 输入、五阶段产品过程、H3 故事样片、作品展示和品牌下载卡连接起来。5 个 6 秒 H3 片段由提示词生成、母版剪辑与后期图形层组合；最终成片各层不是由 H3 单次直接生成。

这些是对这条成片的观察，不是所有 AID Partner 视频的强制品牌规范，也不是字幕可读性/转化率的量化验证。复用之前应按目标画幅、题材、平台 UI、真实产品能力、品牌规范、文案长度与声音节奏重排；不要直接复制本片颜色、Logo 位置、字幕坐标、BPM、时长、文案或角色画面。
