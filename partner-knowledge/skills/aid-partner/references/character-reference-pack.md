# 角色参考包与跨镜头一致性

用于反复出场的角色。先复用已确定的角色库与素材，按计划镜头补缺，不强制生成固定张数的转面图。

## 区分身份与本场状态

稳定身份包括已确定的面部特征、发型、体态比例和辨识特征；本场状态包括服装、道具、伤痕、湿发或污渍。这些状态可随剧情变化，记录开始镜号、变化原因和后续延续范围，不让每镜恢复成最初的干净造型。

参考图应覆盖实际拍摄需要：正面或三分之四面用于辨认，侧面用于侧拍，全身用于比例与服装；表情和光线变化有助于说明同一身份的不同呈现。优先清晰、单人、五官可辨的素材，避免用重滤镜、遮脸或几张几乎相同的姿态补数量。仅一张参考图时可以继续工作，明确未建立的角度，不承诺隐藏侧面已被准确确定。

从一张图生成其他角度只是候选设计，不能证明真实人物未见部分的外貌。候选未经用户选定，不替换正式角色。用户只要求修改提示词时，不额外制作参考图或训练人物模型。

## 保存与使用

通过 aid_import_asset 导入实际文件；用户选定后用 aid_save_character 保存当前工具支持的角色信息。更多角度、服装版本、素材职责及镜号映射可写入项目 story；不虚构角色工具的字段。每镜选择最相关的参考，不能把整包无差别上传。

图版含多个角度时，提示词说明使用哪个人物和哪些特征，避免把转面图误当多个人物场景。是否能理解图版取决于所选模型；只有首帧输入时，不把整张角色图版当电影开场。

角色音色独立于面部身份，按项目保存和显式指定；相同脸部参考不代表音色已克隆。跨模型可复用已导入图像和文字设定，不能把某平台人物训练 ID 当通用参考 ID。

示例：第 3 镜角色淋雨后，第 4—6 镜沿用湿发与湿外套状态；正面身份图仍用于面孔参考，但不据此恢复干衣。用户更换外套设计时，按镜头依赖指南识别涉及该服装版本的镜头。
