# 制作放行、版本与最终验收

用于完整影片制作、局部返修和最终导出。源头措施降低生成失败概率；内容验收阻止已发现或未核实的错误进入交付。二者不能保证生成模型永远不犯错。本文件规定 Agent 如何执行和记录，不代表 Partner 已实现自动拦截器、转写器或自动评分功能。

## 1. 把要求绑定到真实资产

在项目 `story` 维护一份制作台账，长表可保存到本地文件并在项目中链接。使用已有字段与真实 ID，不新增工具参数。

- 锁定要求：参考身份/风格、逐字台词与语言、画幅、声音路线、允许导演调整的范围、标准速度/交付速度及结尾要求；注明来自用户还是本次制作决定。
- 每个生成段：所属镜号和全片区间、项目修订号、参考素材 ID/版本/实际上传顺序、实际 prompt、路线及输入参数、taskId、候选输出 ID。
- 每条被采用素材：输出 ID/路径、文件哈希或不可变版本、实测尺寸/帧率/时长、采用的源入点/出点、目标时间线区间、声音来源及原生音轨保留/移除情况。
- 每次检查：检查对象的版本和保留区间、检查项目、实际结果、证据文件或可定位的观察记录、检查者/工具与覆盖范围。单项状态用 `未验证/通过/失败/不适用`；整体只有适用项全部通过才可采用。不适用必须有理由。

文件名含“终版”、工具 completed、文字描述“已修复”或零个报错都不是验收证据。用户明确报告硬性错误后，把对应输出标为失败并记录时间位置；未定位根因时不要删除反馈，也不要用之前的通过记录覆盖它。

## 2. 生成前检查与代表性片段

全片设计和代表性分镜按既有流程完成后，再检查实际执行计划：

1. 查看真正将上传的首帧和每张裁图，而不只看原角色卡或缩略图。多人图逐人核对脸、发型、身体结构、服装、人数和道具；装饰性角色卡的金框、底座、标签不自动继承到电影画面。原始身份参考保留为比对基准，后续生成图不能反向覆盖它。
2. 核对各模式的真实素材职责。某张图写在项目 references 中，不等于它已进入请求；辅助参考也不等于有时序约束的关键帧。缺少正确首帧时不能只因上一镜可用就自动复用；先核对人物、道具、地点和动作阶段全部适合当前镜头。
3. 检查镜头的执行负荷。多人相似面孔、遮挡后首次亮相、身体全貌、道具交接、多人密集对白和复杂运镜同时存在时，减少非必要变化，给关键状态明确图像锚点；允许剪辑时拆成清楚的覆盖镜头。用户锁定无剪辑时保留镜头要求，不能用暗切掩盖失败。
4. 从既定视频任务中优先完成最能验证该路线的高风险代表段，例如多人开门揭示或近景对白。先确认这类输出达到要求，再展开同类视频任务；这不是额外增加测试镜头。一个成功片段只支持相似条件，不证明所有人物、镜头或声音情况都通过。
5. 图片服务支持并行时，可以在共同人物/风格设定已锁定后并行独立分镜；镜号、ID与参考映射预先固定，不能按完成先后决定顺序。依赖上一段真实末帧的续接须等待该段完成且可采用。失败涉及共用参考或声音路线时，暂停尚未提交的同依赖任务，保留无关任务进度。

连接可用、节点齐全、API预览正确，只验证技术链路。代表性片段和后续各段仍需内容检查；发现问题先改错误输入、参考绑定、声音路线或过载设计，不仅更换seed原样反复试。

## 3. 片段验收：检查整个被采用区间

按实际素材和实际时间检查，不用计划秒数替代：

| 检查对象 | 必须核对的内容 | 证据边界 |
| --- | --- | --- |
| 画面内容 | 身份、人数、身体结构、持物主人、空间/动作连续性、网格/边框/乱码、明显变形与闪烁 | 抽帧用于定位，不能据几个静帧证明整段没有瞬间错误 |
| 高风险事件 | 门开后、遮挡揭开、转身、入画/出画、道具交换、段内切镜 | 连续查看事件前后；短暂错误需逐帧或更密集核对 |
| 对白和声场 | 锁定文本、语言、说话人/顺序、口型需求、允许的非语言声、额外人声、音乐遮盖 | 按对白指南转写并实际听检，空转写不能证明无怪声 |
| 技术输出 | 实际画幅、方向/旋转与显示比例、分辨率、帧率、时长、音视频流、可解码 | 16:9容器不证明内容未拉伸/裁掉人物；需查看可见画面 |

以视频播放/理解能力连续检查全部保留区间；宿主只能读静帧时，记录抽样时刻与遗漏风险，不能写“全片视觉验收通过”。只读取字幕或波形不能写“已听检”。可用工具缺失时先保存候选、检查记录和待确认项，继续不依赖这些能力的工作；最终只能如实标记为待审预览。

源片局部正确可以只采用该段，但应单独记录通过的 `[sourceIn, sourceOut)`；不能因为前几秒正确就给整条素材盖章。裁掉错误必须保证剧情、完整动作和锁定台词仍然成立。需要重生时保留故障证据、修改原因和新版本，按既有授权及有限尝试范围执行。

## 4. 防止返修后旧错误回流

修订可接受状态为：`待验收→通过/失败`；引用或文件内容变化后旧检查变成`过期`；被选定新版取代的旧输出标记`已替代`。这些是制作台账状态，不冒充工具原生状态；保留旧文件供回退，合成清单只引用当前通过的版本。

- 改人物参考、分镜、声音、prompt或片段保留区间后，沿真实依赖标记需要重查的项；不能把旧输出自动升级为采用新参考的成品。文字修订不等于视频重生。
- 每个剪辑条目分别绑定视频来源与音频来源。替换画面时若保留旧音频，必须证明该音频仍是锁定台词、说话者正确、时间同步；替换声音后确认错误旧音轨真正移除。
- 局部返修要检查“修补前→修补段→回切旧段”三个交接，尤其回切后首次完整显露人物/道具的位置。不能只验证用户指出的一个时间点。旧段已知错误区间不得通过回切重新进入母版。
- 用户时间点先绑定具体文件版本、标准速度/交付速度和实测剪辑映射。若仅做整片恒速变换，源时间可按倍率换算；已经裁剪、拼接、变速或延长时，必须使用逐条源入出点映射，不能只乘1.2推算全部位置。

## 5. 最终文件另行验收

合成前检查采用表无缺口、重叠或重复表演，所选文件和哈希仍匹配通过记录；未验证/失败/过期/已替代项不得自动进入最终导出。明确预览需要时可以导出待审版，但命名和交付状态不能称终版。

合成、混音和整片变速之后，对最终实际文件重新核对：

- 从头到尾音画联合查看，逐条对照对白总表；所有修补点、切点和回切后显露状态单独检查，确保无重复/截断台词、双重音轨、无意黑帧或旧错误回流。
- 检查故事因果和声音触发是否仍可读；插入镜头、声音替换或加速不能让角色提前反应、旁白描述已不存在的画面，或把呼吸留白剪没。
- 保留标准速度导演计划，沿用项目已确认的整片变速要求；另记录最终实测时长、对白可理解度和结尾留白实际长度。倍速不会自动保证表演成立，失败时在已有创作授权内调整，用户锁定条件冲突时明确指出。
- 用户要求结尾长镜头时，在前期说明最后结果、构图、持续动态和声场，最终检查没有突然切断或明显循环。冻结帧、慢放、重复帧和真实连续生成是不同处理，不能只凭补长后的秒数声称已得到新长镜头。
- 检查完整解码、尺寸/显示比例、帧率、音视频时长与同步、首尾干净，并确认交付链接指向实际验收的那份文件。

最后报告三个独立事实：文件是否已导出、哪些内容已验证、还存在哪些未验证项。技术通过不能代替内容通过；一次内容通过也不证明该工作流以后能免检。
