# AI 叙事镜头：从故事证据到可生成的时序

适用于短剧、电影片段、多镜头连续叙事，以及图生视频里的动作/运镜冲突。先沿用[故事先行](story-first-and-series-continuity.md)和[导演因果链](director-storytelling-and-shot-causality.md)，再解决生成与剪辑的落地问题。不是新的API、自动评分系统或强制增加测试片的流程。

本指南将官方制作与提示词资料转化为Partner的原创工作方法。来源与迁移边界列在末节；数值、检查表和示例是本地设计，不冒称厂商保证或已实测成功的配方。

## 1. 先设计观众必须看懂的证据，不先凑镜数

每个剧情拍先写：**观众原先以为什么 → 看见/听见什么证据 → 判断怎样改变 → 引出谁的下一次行动。** 再决定需要哪些观看机会：空间/关系、决定性动作、可见结果、人物响应。可以在同一镜头里完成，不机械扩成四镜，也不默认正反打。

- 反转靠道具时，前镜建立用途，揭示镜让证据可读，后镜让证据改变选择；不能只有道具特写加惊讶脸。
- 双人对抗需要看清控制权怎么改变，可保留同框证明距离、接触或退让；反应比动作更重要时才交给反应者。
- 接缝记录动作进度、身体/道具状态、视线目标、屏幕运动方向、观众正在寻找的位置及延续的声源。下一镜继承这些状态，不重复演一次“刚发现”。
- 用已有分镜按拟定时长顺读，检查不靠解释能否读懂因果、证据是否提前泄露、对白与反应能否装下；必要时用现有素材粗排，不借“动画预演”自动增加付费任务。

镜头为何存在仍由故事决定。留白、环境和余波可以有叙事功能，不因没有新动作就删除。

## 2. 按必须读清的事件分配生成负荷

复杂度不只看动作数量，还看新身份出现、遮挡后重现、接触/交接、空间重建、对白轮换和真实切镜同时发生多少。

1. 先锁关键事件及理解它必需的前因、过程、结果。
2. 将次要动作排在主事件前后；能并行的背景变化仍写清，但不抢证据或盖住关键对白。
3. 时长不足时，在故事许可内调整调度、构图或生成分段，不删关键因果，不把每段统一成“一人一个动作”。
4. 精确切点上的证据/表情可按已确认方案分镜生成后剪；需要证明接触连续的动作，优先保留连续视野。不得擅自拆掉用户锁定的一镜到底。

时间码是表演与剪辑目标，不是模型帧级保证；多镜头模型不等于无限装剧情。沿用[成段生成](storyboard-segment-generation.md)核实当前模式容量。BPM仍按情节选值、换算秒/拍并在实际提示词映射重音；自然对白不强制每字踩拍，不统一128 BPM，也不以BPM代替动作时序。

## 3. 首帧既有外观，也有运动暗示

图生视频不只检查脸和服装：倾斜重心、脚离地、绷紧布料、轮胎扬尘、拖影、飞溅液体都可能暗示继续运动。文本要求静止而图像暗示运动时，先处理输入冲突，不能反复加“不许动”。

检查后续动作的空间条件：画幅是否容得下抬臂，门能否打开，横移后要揭示的区域是否存在，起始特写能否合理退到全身。首帧是动作起点，不总是最漂亮或最高潮的一帧。

不能为了锁人而在首帧提前露出反转：身份参考与实际开场构图分工；模式无法兼顾时说明风险，按授权调整路线。首尾图的位置、持物、朝向或空间若不可连续到达，先补过程或改图，不能期待模型用变形填补。普通参考图不自动成为指定时刻的关键帧。

## 4. 摄影机、主体、环境是三条独立运动轨道

分别写起点、触发、路径/轴线、幅度、速度曲线、终态与持续性，再说明互相的因果。不能把“画面向右”当成摄影机右移，也不能把“人物始终居中”当成机位固定。

| 摄影动作 | 必须澄清的物理关系与观看结果 |
| --- | --- |
| 固定机位摇摄 pan/tilt | 机位不平移，围绕哪条轴转；起始对象、经过区域、最后信息点 |
| 推轨/后移 dolly | 机位实际接近/远离，主体尺度与前后景视差如何变化；不是只放大画面 |
| 变焦 zoom | 机位不动，焦段改变取景范围；不能同时要求固定焦段 |
| 横移/跟拍 | 相机与主体各走哪条路线、相对速度、主体画内位置、背景相对位移 |
| 环绕 arc | 围绕谁、哪侧路径、起止观察方位、遮挡经过顺序；不是人物自转 |
| 转焦 | 从哪个距离的对象转到哪个对象、触发与到达时间；不等于推近 |

术语落到本镜空间；厘米、角度、秒数是导演目标而非模拟器精度承诺。移动揭示须写“起初看不见什么—经过哪个遮挡边缘—何时变得可读—终点保留什么”。固定摄影机不等于冻结人物和环境。轻微手持与短暂失焦按片子需要使用，不能让证据刚出现就被晃动和模糊遮掉。

## 5. 参考素材按职责分配，不按数量堆叠

每个实际输入记录 **绑定标签 → 采用的属性 → 不采用的属性 → 覆盖镜号/时段**。身份参考不负责场景光线，运镜参考不负责源视频人物或音轨，构图参考不自动规定服装；文字排除也不能保证模型完全隔离属性。

同一属性冲突时，依用户锁定项选唯一基准并修正素材，不能同时传白天与夜景并要求“严格一致”。运动/视频/音频参考、首尾帧与多图能力必须通过真实工作流核实，不能因别的平台支持就虚构输入。四宫格四状态不等于四个切镜，整板也不是通用时序控制接口。

跨段复用原始身份与环境基准，不只逐段拿漂移末帧当新标准；末帧提供接缝状态，不能覆盖已确认身份。依赖沿用[局部修改](shot-dependencies.md)。

## 6. 完整导演稿，紧凑但不丢信息的模型稿

先用[参数语法](prompt-parameterization-grammar.md)与[动作七槽](action-seven-slot-precision.md)写完整变化，再压缩表达；不能先写模糊短句，让模型补导演工作。

- **请求内恒定项写一次**：实际参考绑定、必要身份、空间、光线、连续性。不在每个秒段重述整套服装与质量形容词。
- **变化项在发生处写全**：主体ID、左右执行部位、动词、对象/接触点、方向/幅度/速度、次数/时长、前后状态。表情、相机、光影、材质响应和声音有变化，也须有明确包络；不能因“图里能看见”省略后续过程。
- **独立请求各自完整**：去掉聊天历史仍可执行，不用“接上镜、同上”替代必要设定与实际进入状态。请求内去重不等于请求间丢掉锚点。
- **情绪不能代替动作**：先定触发，再选可见信号；不把“迟疑”展开成笑、哭、退后、冲上前等竞争反应。七槽不等于增加无叙事功能的小动作。
- **先说该发生什么**：用过程与终态控制动作，少量必要否定按模型能力处理。Runway某版不支持负面提示不代表H3一律禁用；不能把SD权重括号、他厂相机标签移植进H3。
- **描述不是节点设置**：文本焦距、时间码、BPM不替代真实时长/尺寸/帧率字段；seed也不是身份锁定保证。

最后按[H3编译规则](prompt-case-transfer-and-h3-compilation.md)输出中文正文、真实素材标签、Shot和声音结构；不把内部检查表机械塞进模型。压缩后对回导演稿，保护左右、触发、交接、加减速、揭示时机、终态与逐字对白。

## 7. 原创练习：同一证据，两个拍法

剧情已定：女儿以为父亲不愿送行；他让出门口，露出早已修好的行李箱，她因此放下争执、走向箱子。练的是表达，不照搬来源样片。

- **连续揭示**：双人侧面中景，父亲遮住门内箱子；女儿停止说话后，父亲向自身左侧让开，相机从走廊侧向门口横移，到女儿能看见箱子的位置减速停稳；箱子露出后，女儿才视线下移、右手松开紧抓的衣角。移动服务于从“挡路”到“帮忙”的认知变化，不为炫技环绕。
- **剪辑揭示**：双人镜先确认视线与门口关系，让位后切女儿视点中的箱轮修补痕迹，再回反应；继承让位结果，不让父亲再让一次。若修补痕迹决定剧情，此前故事必须已建立损坏事实，插入镜须让形状清楚、有阅读时间。

空间与让路动作是核心，选连续；特定细节是证据且全景读不清，选分切。都保留女儿的下一选择，不能在漂亮道具特写处断线。以上是导演表达稿，**不是可直接提交的完整prompt**；须按本片时长/BPM、七槽、真实图号和H3结构补全。

## 8. 出错先定位，不无限改词抽卡

| 可见问题 | 先核实 | 授权范围内的最小修改 |
| --- | --- | --- |
| 要求静止却持续前冲 | 首帧倾斜、扬尘、拖影的运动暗示 | 修起始状态，保留其余变量 |
| 镜头到了，证据仍看不清 | 景别、遮挡、焦点与阅读窗口 | 改构图/焦点/时序，不堆高清词 |
| 交接后有两个道具 | 持有者、接触顺序、释放时刻 | 补交接；必要时重设计拍法，不删剧情证据 |
| 单段好看但接不起来 | 出入状态、方向、声源与知情状态 | 修接缝及依赖片段，不默认全片重做 |
| 脸/服装逐段漂移 | 原始基准是否真实输入 | 恢复正确基准，重查受影响依赖 |
| 漏动作、乱切镜、吞对白 | 单段负荷与时长 | 保留因果重分段，不改锁定台词或擅换后期配音 |

修订记录“观察到的问题—待验证原因—本次主要变量—保持项—预期变化”。未验证原因不能称已定位；关联修改须说明依赖。付费试验、重生成及批量变体须已有授权与次数/预算边界，不把来源的“多试几组”变成默认流程。本指南不新增自动审美质检。
