# 提示词参数语法：用一套简洁结构定义画面与时间

用于所有图片和视频提示词。动作七槽只是人物动作的领域格式；摄影机、光线、阴影、焦点、道具、表面质感、软硬、弹性、布料、毛发、液体、颗粒和声音也必须用可观察、可比较和可继承的参数定义。

## 1. 统一变化包络

任何会变化或会改变其他元素的对象，都使用同一个八段包络：

```text
[E:对象ID.区域/部位]
初态{...}
-- 触发{...} -->
过程{路径/轴线/...;幅度/范围/...;速率曲线/...;时长/次数/...;交互/物理响应/...}
=> 终态{...;持续到...}
```

展开为八个问题：

1. **对象/区域**：谁或什么的哪一部分？
2. **初始状态**：位置、方向、形状、速度、亮度、接触、材质或归属此刻是什么？
3. **触发**：哪个动作、声音、接触、时点、拍点或信息使它开始变化？
4. **路径/轴线/方向**：沿什么直线、弧线、表面、深度轴、光轴或变形方向变化？
5. **幅度/范围**：移动、旋转、变形、亮度、色温、焦平面或受影响区域改变多少？
6. **速度曲线与时间**：何时启动，如何加速/匀速/减速/回弹，持续多久、几次？
7. **交互/物理响应**：它与谁、什么表面、光线、空气或声场相互作用，产生什么受力、遮挡、反射、摩擦、形变、振动或响应？
8. **终止状态与持续性**：最后在哪里、变成什么，是停住、保持、恢复、衰减还是交给下一拍？

这是内部审计结构，不要把每个提示词写成表格。成稿可以压缩成一句：

```text
[L:key]初始从S1画面左后侩45°照入、色温5600K、亮度不变；当门在2.0秒打开时，0.4秒内从35%线性升至65%，只扫过S1右脸和肩部；阴影向画面右前方延伸，边缘过渡宽度由2厘米增臶8厘米，3.0秒后保持到本镜结束。
```

## 2. 参数要可观察，不伪造无意义精度

优先使用模型和人类都能理解的参照：秒、拍点、次数、度数、厘米、米、一个手掌宽、一个肩宽、一步、画面百分比、曝光档、色温、粗糙/镜面范围、阴影边缘过渡宽度。

只写影响画面、动作、物理响应或连续性的参数。不知道精确材料模量时，不伪造“肖氏硬度72”；改写为可观察响应，如“右手食指指腹向下按至指尖皮肤轻微变白时，表面下陷约2毫米；松开后0.15秒内恢复，无永久折痕”。

## 3. 领域参数包

统一变化包络之上，只加当前元素必需的领域参数。

### A. 人物、生物和机械动作

使用 [动作七槽](action-seven-slot-precision.md)：主体ID、精确执行部位、可视动词、对象/接触点、方向/幅度/速度、次数/时长、起止状态/道具归属。

### C. 摄影机与焦点

```text
[C1]起位/机高/与主体距离/开场构图
--故事触发-->
路径形状+方向+距离/角度+速度曲线+遮挡/视差+焦点交接
=>机位/构图/焦平面/最终速度
```

必须区分光学变焦、摄影机物理位移和拉焦。“推近”至少写明是机身前移还是变焦，从多远到多远，在何时加速/制动，最后什么占画面多少。

### L. 光线与阴影

```text
[L1]光源类型/位置/相对角度/发光面大小/颜色或色温/初始强度
--触发-->
强度或位置曲线+受光区域+反射/遮挡
=>最终亮度/颜色/保持时间
[Shadow:L1]投射方向/长度/透明度/边缘过渡宽度/移动与最终形状
```

“柔光”必须落到较大发光面、较宽半影过渡和较低局部反差；“硬光”落到较小/较远发光面、窄边缘过渡和清楚遮挡轮廓。不只写“电影感暗光”。

### M. 材质、软硬、质感与弹性

```text
[M:物体ID.区域]厚度/结构+硬度或顺应性+表面粗糙/光泽/纹理尺度+摩擦
--受力点/方向/大小/时长-->
形变方向/深度/范围+回弹速度+阻尼/振荡次数+滑移或附着
=>恢复/永久形变/破损与残留状态
```

将常用形容词翻译为响应：

- `硬`：同等受力下可见形变极小，碰撞停止快，可产生脆裂、反弹或高频声，按剧情选定。
- `软`：写受力点下陷多深、影响半径、卸力后多久恢复。
- `有弹性`：写最大伸长/压缩比、松开后的回弹路径、超调量、振荡次数和停稳时间。
- `粗糙`：写可见凸起/纤维/颗粒尺度、高光是否破碎，以及与手/地面接触时的摩擦结果。
- `光滑`：写高光形状和清晰度、表面纹理是否可见、接触物是滑动还是停住。

### D. 布料、毛发、液体与颗粒

写明固定点/来源、外力来源和方向、受影响区域、主运动路径、幅度/频率、滞后、阻尼/衰减、与身体/地面/空气的碰撞，以及末状态。“飘逸、灵动、水花四溅、尘土飞扬”不能代替发生位置、初速度、轨迹、颗粒尺度、扩散范围和衰减时间。

### S. 声音

写声源ID和位置、触发、起音、响度轮廓、音高/音色、持续时间、空间反射/遮挡、衰减结束和画面中谁能听见。“震撼音效”不能代替什么物理事件发声、何时到达峰值及如何衰减。

## 4. 简洁不等于省略因果

使用ID和范围继承减少重复：

- 在段首定义一次`S1`、`PROP1`、`C1`、`L1`、`M:PROP1.surface`；之后沿用ID。
- 未变的参数用“保持至本镜结束”锁住，不逐秒重写。
- 只在触发发生时开新的变化包络，不为每秒机械重复整套属性。
- 同时变化的元素各自有包络，再用共同时段/拍点对齐；不把人物、运镜、光线和声音混成一个无主语长句。

## 5. 参数化门禁

提交前对每个实际变化的元素检查：

- 对象ID和作用区域是否唯一？
- 初态是否与上一拍/上一镜终态一致？
- 触发是否是明确时刻、拍点、行动、接触、声音或信息？
- 路径/轴线、幅度/范围和速度曲线是否可观察？
- 交互是否具体到接触、遮挡、反射、摩擦、变形、振动或声源？
- 终态是否说明停止、保持、恢复、衰减、损坏或新归属？
- 删掉“电影感、梦幻、紧张、轻柔、硬朗、高级、真实物理”等形容词后，模型是否仍知道要改变什么、如何改变、何时停止？

任一项失败就退回提示词阶段。参数化不是堆数字，而是消除能影响结果的歧义；没有叙事、构图或物理价值的参数不写。
