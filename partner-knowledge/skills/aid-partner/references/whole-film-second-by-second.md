# 全片逐秒视听设计：从完整电影到分镜与生成段落

用于叙事视频的剧本落地、分镜和生成提示词，尤其是长片、喜剧以及“段落有情节但镜内拖沓、废画面多”的修订。先让整部电影在标准速度时间线上成立，再确定连续镜头，从预想动态中抽取分镜关键画面，并划分模型任务。分镜图是动态过程中的画面样本，不等同于一次剪辑镜头。十五秒钩子只是宏观检查点，不能代替其间每一秒的具体设计。

## 1. Skill作为导演，先完成全片和代表性分镜，再归类分组

依赖顺序：**主题与完整因果故事线 → 从开场到结尾的逐秒视听时间线（含镜头视点和衔接）→ 按剧情设计连续镜头与真正切点 → 全片代表性动态分镜全部出齐 → 按情节归类并结合真实时长/模型容量划分生成段落 → 逐图表演与过渡编译为详细段落提示词 → 生成并按全片时间线剪辑合并。** 全程按标准速度规划，整体加速只在母版合并后执行。

- 两分钟需要覆盖全片0–120秒；五分钟需要覆盖约0–300秒。先有完整结尾、伏笔回收和全片可执行时间线，不能只细写开头，后半段仍是“继续升级、温暖收尾”就开始整片生成。
- 允许分批编写文字，但批次属于同一份全片计划：沿用统一绝对时间、人物与道具状态、观众知情、待兑现伏笔和最终方向。进入全片付费制作前汇总检查；用户单独授权的小样可以只执行已细化范围，不能把小样当整片设计完成。
- 进入整片制作时，先把全片有代表性的动态分镜全部出齐：复用用户已确认图片，按授权生成缺少的四宫格/关键画面，裁切并导入；之后才按情节归类成段。只请求剧本或文字设计时完成分镜设计表并如实标注未生成，不擅自付费生图。制作前可以先核对模式容量与素材语义，但不据此提前把故事装进固定容器。
- 每段来自全片已设定的时间区间。任务分开不意味着故事重启；不在每段开头重复定场、角色亮相、起步或重讲目标，也不在每段末尾默认安排凝视、空镜、停住和淡出。
- 本项目明确区分：**全片时间线**是整片发生过程；**镜头**是一次连续观看/摄影过程，只有明确剪辑才产生新镜头；**分镜稿/分镜图**是从预想动态中抽取的关键画面；**生成段落**是一次模型任务的时间容器。镜长由剧情决定，可3秒、10秒或更长；没有默认镜长。
- 同一镜头可用分镜图K01、K02、K03表达起始、中途、到达状态。摄影机和人物从图1走向图2再到图3，不因图号变化而切镜、交叉淡化、静态轮播或瞬移。逐秒文字负责连接图间的真实运动与表演；也可只用一张图约束简单镜头。
- 每张分镜图记录所属镜号、全片/段内目标时刻、人物/道具状态、摄影机位置与方向、构图/焦点、可见和暂时隐藏的信息。关键画面数量由需要约束的变化决定，不按秒数等距抽样。图像本身是一个时刻，不能给每张图默认分配一个独立镜头时长或累加重算段长。
- 镜头切点服务观众的信息与视点需求。生成边界再按时长、素材容量和实际能力安排；不要把模型的15秒或30秒容器提前当剧本单元，更不能把五分钟先均分成20个十五秒小品。

同镜需要多状态控制时，优先用 [四宫格动态分镜](four-panel-motion-storyboards.md) 统一生成关键状态后裁成四图。四格是连续动态的取样，时刻由剧情决定；图间仍需完整时间化提示词，不能把四格变成四镜或把镜长四等分。

## 2. 每秒可追踪，不靠形容词填表

使用全片绝对时间，区间统一为起点包含、终点不包含，如 `[00:00,00:01)`、`[00:01,00:02)`。可用小数秒描述动作落点、对白起止或有必要的停顿；一秒是设计检查的粒度，不是强制切镜节奏。一个动作持续数秒时写出它的阶段、阻力或注意力变化，不能仅用“继续”“缓慢地”覆盖一整段。

先写该场的稳定设定：人物身份服装、空间位置与方向、道具状态、光线色调、基础声场。逐秒记录继承这些事实，只细写当前变化，避免每行重复整套美学词。没有人物的镜头明确写无人入画；无对白明确写无对白及实际声音，不强塞表情或台词。

每个时刻都应能回答下面的问题。可把相邻内容写成自然段，但内容不能缺失：

| 维度 | 需要落到画面或声音的内容 |
| --- | --- |
| 观众看哪里 | 主体、景别、机位、构图、前后景关系，焦点或摄影机是否移动；运动由什么触发、从哪里到哪里。 |
| 人与环境在做什么 | 具体动作的开始、推进、阻碍和结果；人物位置、朝向、手中物件；画内及与后续有关的画外事件。 |
| 表情与情绪怎样变 | 触发事实 → 眼神/面部/身体/呼吸的可见变化 → 随后的选择。写“抬起的下巴放下，手从门把缩回”，不能只写“复杂、纠结、感动”。 |
| 听到什么 | 说话人、逐字对白、开始与结束、语气及对白期间的动作；环境声、物件声、画外声、音乐或静默的变化与来源。 |
| 此刻为什么保留 | 新事实、观众认知改变、压力增加、关系变化、行动进展，或让既有信息被读清所需的时间；结束时是什么状态、下一时刻如何接走。 |

“他寻找钥匙，越来越着急，镜头缓慢推进”不足以支撑八秒。应决定哪秒摸哪个口袋、手为何停下、观众何时先看见钥匙、谁注意到、哪句对白暴露误判、摄影机何时把注意力交给真正信息。若现有事件只需要三秒，就先按三秒设计，不让模型自行拖成八秒。

## 3. 密度由因果和可读性决定

每一秒都要有观看价值；这可以是同一动作的必要推进、线索逐渐可辨、危险接近或人物压住反应，不要求每秒发明一个新事件或反转。环境、道具和无对白空镜同样能推进故事。

- **剪掉后的损失**：对看似闲置的区间问“去掉这段会丢失什么具体信息、动作可理解性或情绪转变？”没有可说清的损失，就删除、缩短或与其他信息同时表达；“有氛围、显得电影感”不能单独解释停留长度。
- **停顿有进入和退出条件**：写清观众在等什么、停顿中哪项压力/认识仍在改变、哪个动作或声音结束它。不能把“反应两秒”“留白三秒”设为每镜默认。
- **表演有现实时间**：不要一秒内完成长距离移动、取物、认读、思考和长句对白。对白按可表演语速安排到完整区间，允许跨秒连说，禁止为填表逐字蹦读。需要密度时可让说明与行动、画外声与反应同时发生，但同一注意力时刻保留清楚主次。
- **进场已有行动，离场已有结果**：不必展示所有走近、站定、准备和转身。转场时用前一动作/声音/视线把注意力交给下一信息，下一镜不重演已经完成的动作。
- **全片时长由有效内容支撑**：目标约五分钟时，在授权创作范围内用新策略、后果、关系变化和兑现支撑时长；不要把只有三分钟有效内容的设计拉慢到五分钟。用户锁定剧情、对白或时长无法同时满足时，指出具体缺口，不暗改或填充。

先按上述要求写出足够具体的内容，再检查语言是否清楚。细致指可执行的时空和状态变化，不是堆形容词、同义禁令或每秒相互冲突的运镜。

## 4. 把钩子设计转成模型可表现的内容

“钩子、反差、反转、递进、变化”属于导演设计，不能代替实际生成提示词。项目计划可以保留这些分析标签；生成正文必须写清观众先看到什么、随后哪个具体事实打破或改变理解、人物如何反应并采取下一步行动。不要只要求模型“制造反转、加强冲突、节奏紧凑”。

| 设计意图（留在导演计划） | 应写入提示词的可见/可听过程 |
| --- | --- |
| 反差 | 指定同框或相邻镜头中真正冲突的事实及主次：他挺直背说“我全准备好了”，另一只手却在桌下把散落证件胡乱塞进包；镜头留出桌下空间，让观众看见台词与行动的不一致。 |
| 反转 | 先给足具体预期，再有依据地揭示相反事实：他向母亲伸手索要钥匙；她不回答，只点他袖口上自己的蓝补丁；他认出穿错外套，手收回、声音止住，转向自己的衣服。新信息改变下一步行为。 |
| 递进 | 写出前一个动作造成的下一层困难：他推抽屉藏住账单，纸角卡在缝里；再用力时撞响杯子，引来门口脚步；他停手把身体移到柜前遮挡。不能用“越来越紧张”替代这条过程。 |
| 情绪或关系变化 | 给出触发与表演转向：他抬手准备反驳，看见母亲拇指的创可贴，张开的嘴合上，接过她手里的重袋；母亲原本解释的话停下，松手后跟上。不要只写“终于长大、深刻温暖”。 |

这些只是写法示例，不能凭此向已有故事添加未经铺垫的物件或事件。按当前剧本把过程安排到具体秒段，并规定信息何时可见、声音何时发生、动作怎样改变状态。生成正文即使删去所有“钩子/反转/递进”字样，也应足以让相应效果在画面中成立。段落边界不能把铺垫与兑现之间的因果抹掉。

## 5. 五张动态分镜归为一组：一个连续镜头的详细提示词

本例取全片00:36–00:46的十秒连续镜头，仅为说明写法；十秒、五张图和下列落点都由这段具体动作决定，不是模板。此前剧情已交代青年急着独自办事，钥匙在自己的深色外套右袋，但他误穿了母亲偏短的灰外套。

稳定设定：玄关鞋柜靠左，青年在右、母亲在左；灰外套袖口有蓝补丁，深色外套挂在青年身后伸手可及的衣钩；同侧窗光、自然肤色，没有配乐。摄影机始终在鞋柜同侧、人物不换站位，固定焦段，通过实际移动和升降改变构图。

**先完成全片分镜后，把同一镜号S08的五张预想动态抽帧归为本组：**

| 分镜图 | 全片/段内时刻 | 关键画面与职责 |
| --- | --- | --- |
| K01 | 00:36 / 0秒 | 腰部中近景，青年右手刚探灰外套空袋；母亲左侧半身在画内。锁定起始姿态和空间。 |
| K02 | 00:38 / 2秒 | 青年已抽手摊向母亲，短袖口露出；母亲在左侧看向袖口。锁定询问后、发现前的动作阶段。 |
| K03 | 00:40 / 4秒 | 同侧相机已靠近手臂，袖口蓝补丁成为主体，母亲食指点在补丁上，青年右手保持摊开；不先看到他认错的表情。锁定发现证据的构图。 |
| K04 | 00:44 / 8秒 | 同侧双人中景，青年右手刚从深色外套提出钥匙，肩膀放下，母亲仍在左。锁定错误已证实但尚未求助的状态。 |
| K05 | 00:46 / 段末 | 相机已后移抬高到双人中景；青年右手握钥匙、肩膀放松，母亲接住他卡住的拉链头。锁定关系改变后的到达状态。 |

五张图须共同成立于同一空间、人物身份和连续路径；若透视、站位、道具归属互相矛盾，先修分镜，不要求模型用跳切或变形硬接。目标时刻是导演意图；普通多图参考不是有保证的时间关键帧接口。

| 全片时间 / 段内秒 | 具体视听过程：全程S08，无切镜 |
| --- | --- |
| 00:36–00:37 / 0–1 | 从K01开始，青年摸到空袋底，向门迈出的脚停住；摄影机保持手和口袋可读，只有布料声。出门动作受阻。 |
| 00:37–00:38 / 1–2 | 他抽手朝母亲摊掌，略带责怪地问“钥匙呢？”；摄影机随手轻向左调整，袖口露出。 |
| 00:38–00:39 / 2–3 | 母亲没有回答，视线落袖口，左侧伸出食指；青年还摊着手等。摄影机开始沿同侧向手臂靠近，观众跟着她的注意力。 |
| 00:39–00:40 / 3–4 | 她指尖点到蓝补丁，青年手指停止催促；相机走到K03构图，补丁和短袖口清楚可见。信息落地，不加转场。 |
| 00:40–00:41 / 4–5 | 母亲收回食指，开始说“先还我……”；相机平稳后移并抬高，青年低头看补丁的眼神开始进入画面。 |
| 00:41–00:42 / 5–6 | 她说完“……外套。”相机到双人中景，青年眉头松开，理直气壮的手缩回，沿母亲示意看向身后深色外套；认错发生在动作里。 |
| 00:42–00:43 / 6–7 | 摄影机保持双人关系，他侧身把右手探进伸手可及的深色外套右袋，母亲让半步，未离开左侧。 |
| 00:43–00:44 / 7–8 | 他取出钥匙，金属碰响；目光从钥匙回到母亲，肩膀放下。原来的责怪失去依据。 |
| 00:44–00:45 / 8–9 | 他握住钥匙，左手拉灰外套拉链却卡住，低声说“妈……”；母亲看向拉链，准备伸手。 |
| 00:45–00:46 / 9–10 | 他接着说“帮一下。”母亲接住拉链头，摄影机保持K05双人构图。下一秒从她解开拉链继续，不另加凝视收尾。 |

K01→K02用抽手与催问交出注意力，K02→K03用母亲指向袖口引导摄影机靠近，K03→K04通过后移抬高和取钥匙完成认错，K04→K05让卡住的拉链促成求助。每对图之间都有动作、表演、摄影机和声音进程。五张关键画面不是五次切镜；反转也不是一句“发生反转”，而是催问、指出证据、认错、找回钥匙、主动求助的连续行为。

## 6. 从全片计划编译实际提示词

项目 `story` 保存完整故事与全片时间线；每个现有 `shots` 记录保存完整镜头的时长、逐秒 `prompt` 和逐字 `dialogue`，多张分镜图的素材ID可列在该镜 `references`；各图目标时刻、职责及镜头/生成段落映射写在 `story`。一张分镜图不必也不应自动创建一条shot；续用已有项目时保留原ID，补充映射，不擅自重编号。另在 `story` 保存生成段落与全片时间/镜号的对应表，不新增API字段。

每个生成提示词必须自包含：实际素材绑定 + 本段必需的稳定设定/进入状态 + 覆盖本段全部时长的局部时间指令 + 结束状态。模型看不到项目 `story`，不得只写“按剧本”“承接上一段”“参考导演表”。人物卡和分镜图不能替代动作、表情、情绪和声音的时间进程。

- **双时间映射**：全片区间 `[36,46)` → 本段 `[0,10)`；局部时间=全片时间−段落起点。镜号保持全片唯一，若模型要求本段Shot从1开始另存映射，例如S08→Shot 1。后续改时长时同步调整全片后续区间、镜长、段落时长、参考绑定和衔接，不能只改提交参数。
- **逐秒内容进请求**：模型提示词保留每秒的动作阶段、信息落点、表演和声音先后。可合并连续语句、把恒定设定提到段首，但不能把逐秒正文缩回“0–6秒寻找，6–12秒反转”。检查最终实际提交的 `prompt`，不要只检查项目文档。
- **语法与时长真实可用**：普通区间是导演文字；需要H3原生Shot格式时，只在真实切镜处使用`[Shot N] At MM:SS.mmm`；同一连续镜头的图1→图2→图3全部放在同一个Shot内部，镜内的逐秒动作写在该Shot内部，不把每秒都变成新Shot。其他模型按实际支持格式编译。全片累计时间不能直接冒充本次从0开始的生成时间。
- **容器余量不进剧情**：若接口合法时长大于目标剪辑时长，先选择可行边界或合法时长；必要时明确哪部分是供精剪的余量、计划保留区间及实际剪辑工具。余量不计入全片正文，不用慢动作、重复反应或空镜自动补齐。没有相应剪辑能力时重新排可行计划或说明限制。
- **参数不保证时间服从**：逐秒设计提供明确目标，模型仍可能压缩或拖长。精确切点、音画落点依赖实际生成与可用剪辑能力；不承诺提示词实现逐帧控制，不自动付费重跑。用户反馈偏差时定位到全片秒段、具体镜头及实际提交提示词，再在授权范围内修订。

以上十秒应编译成**一个连续镜头**的提示词。实际引用标签按请求预览核对，把K01至K05映射到真实上传列表；下面为已支持多图指导的模式示例，K编号是制作计划别名，不是API参数。若只支持首帧，K02至K05仅为文字目标，必须如实记录，不能宣称五张都已输入。五图可以来自已完成的四宫格和必要的补充关键图，但不能把两个不同动态时刻混在同一张裁图里。

```text
标准速度10秒，一个连续镜头，无剪辑。K01为0秒初始画面，K02为约2秒摊掌催问，K03为约4秒袖口证据，K04为约8秒取出钥匙，K05为段末接受帮助；五张图描述同一过程的不同时刻，不作为五个独立镜头。固定焦段，同侧窗光，自然肤色，无配乐，保留衣料、钥匙声和逐字对白。
青年在右、母亲在左，灰外套偏短、袖口蓝补丁；青年自己的深色外套挂在身后伸手可及处，钥匙在其右袋。摄影机始终在鞋柜同侧，不越轴。
0–1秒从K01开始，右手摸到空袋底，脚停住，保持口袋与手清楚，布料响；1–2秒他抽手朝母亲摊掌，责怪地问“钥匙呢？”，镜头随手略向左到达K02的手势与构图；2–3秒母亲只看袖口并伸食指，青年等回答，相机沿同侧向手臂靠近；3–4秒母亲点到蓝补丁，他停止催促，镜头连续到达K03，把补丁与短袖口给观众看清。
4–5秒母亲收指，说“先还我……”，相机平稳后移抬高，逐渐露出青年低头看补丁的脸；5–6秒她接完“……外套。”，相机到双人中景，他眉头松开、摊开的手缩回，转眼看身后深色外套；6–7秒机位保持，他右手探进那件衣服右袋，母亲让半步仍在左侧；7–8秒他提出钥匙，金属碰响，视线从钥匙回到母亲、肩膀放下，到达K04；8–9秒他右手握钥匙，左手拉灰外套拉链却卡住，低声“妈……”，母亲看向拉链；9–10秒他接着说“帮一下。”母亲伸手接住拉链头，到达K05双人关系。
结尾钥匙在青年右掌，拉链头在母亲手中，下一段继续解拉链。人物沿真实路径动作，摄影机从K01随手势到K02，再靠近到K03，后移抬高到K04并保持至K05；不硬切、不叠化、不把图做成静态轮播，不重新寻找钥匙。
```

提示词越长越需要检查主次与冲突。超出模型实际文本或动作负荷时，先删重复的风格词和无关设定；再在真实叙事边界重分生成任务，保留全片时间线与必要状态，不静默删掉中间表演。

## 7. 生成前的文字复核

这是一轮计划与请求的检查，不是生成后自动评分或新增付费试跑：

1. 全片0到目标末秒都有具体可见/可听内容，所有区间相接；声音和动作可并行，但不能漏一段、重复演一段，或让后半片仅有摘要。
2. 每个秒段能说明观看价值；走路、凝视、慢推、风景、静默和反应都没有被拿来填模型容器。
3. 对白有现实可说完的时间，完整动作有明确阶段，表情由事件触发，同一时间的主体和运镜不矛盾。
4. 镜号与多个分镜关键画面的对应、全片时间、段内时间、任务时长、图像职责与实际prompt能互相对应；prompt覆盖完整本段且没有退化为几句梗概。
5. 全片的观众知情、人物目标、道具归属、空间、声音和伏笔持续传递；分段不重新定场，不在钩子落地后再解释一遍。
6. 先逐秒读一遍，再连起来读整片：局部精细而全片没有推进，回修故事线；全片有转折而镜内空白，回修逐秒视听正文。两者都成立才开始整片生成。
