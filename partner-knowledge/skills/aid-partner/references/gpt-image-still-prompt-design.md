# GPT-Image 静态图：从风格词到可见画面

适用于用 GPT-Image 写文生图或已核实支持参考图的图像编辑提示词。它补充通用[提示词参数语法](prompt-parameterization-grammar.md)，不代替所选服务的输入参数核对。用户提供的八条 Midjourney 古风人像是构图方法的学习材料，不是 GPT-Image 原生格式或已验证的生成效果。

## 从案例迁移什么

先确定这张图的用途和唯一阅读重心，再依次写：

1. **主体与指定瞬间**：人数、年龄段、可辨身份、服装/发型、视线、表情、身体姿势、手与道具的接触关系。静态图只写这一刻实际可见的状态；薄纱、花瓣或光尘若入画，说明它们此刻的位置和遮挡范围，不写视频式“先飘过、再落下”。
2. **构图与留白**：画幅、全身/半身/近景、人物占画面的大致区域、面朝方向、背景承载信息的位置。留白有明确用途（标题、呼吸感、突出目光等）；角色脸或关键道具不可被装饰前景挡住。35mm、三分法只是选择，不是所有古风图的默认值。
3. **空间层级**：保留少数能够交代时代/职业/地点的前景、中景与背景证据；可见但不重要的背景低对比。不要把宫墙、莲池、镜子、灯、花、星尘全部塞在同一张图里。
4. **有限色板与光源**：指定一组主色、少量强调色，以及主光与辅光来自哪里、照到何处、形成怎样的阴影或反射。不是把石青、孔雀石、朱砂、玉、古金等名词并排堆砌，也不默认所有画面都是冷蓝配暖金。
5. **材质证据**：按重点物件分别描述可见纹理和反光：丝绸的织纹与柔和折痕、旧漆的磨损、金属的局部高光、釉面的清晰反射、薄纱的透视重叠。让不同材质有不同视觉响应，别把整张图都做成同一种发亮树脂。
6. **风格与史实边界**：明确选择史实考据、特定朝代启发或架空古风。像“敦煌壁画＋电影3D＋树脂＋玻璃”属于混合艺术方向，不自动等于真实唐/宋/明服饰或文物；要求史实准确时先依据可信资料核对衣冠与器物，不借案例的时代标签冒充考证。

写成一段可读的画面指令即可；以上是内部检查次序，不必把标题或参数表原样交给模型。常量只说一次，限制优先写成可见正向目标，再补少数高风险禁项。若用户给参考图，要明确每张图只负责身份、服装、构图或材质中的哪些属性；未经实际上传的图不能写成已经锁定。身份忠实度与最终画质需看生成结果，本指南不承诺精确还原。

## 不迁移什么

- 删去 Midjourney 专用参数，如 `--s 250`；不要把其数值当成 GPT-Image 的风格强度或 API 字段。目标尺寸/画幅走所选 Partner 图片路线实际支持的顶层参数，提示词中的“竖幅”只表达构图意图，不能代替真实请求参数。
- 英文原稿与中文对照是同一案例，不重复导入两条；八条相似人像不应机械变成八条官方 GPT-Image 模板。
- “8K”“cinematic”“精致梦幻”等只能辅助意图，不能替代主体、站位、受光与材质；画面外的动作轨迹、BPM、运镜、音效和 Shot 时序留给视频提示词重新设计。

## 示例：一张图的可执行骨架

“竖幅环境人像。画面右侧是一位成年古籍修复师，双脚站在桌后，左手压住摊开的纸页左上角，右手用细软刷停在裂口旁，刷毛尚未碰纸；脸与双手清楚可见。桌面与人物为中景，桌前缘一只磨旧的陶砚作低对比前景，后方高书架虚化，不出现第二个人。左侧约三分之一留出暗色安静空间供后期标题。窗外漫射的冷白日光照亮纸纤维和右手，桌侧一盏低亮暖灯只在陶砚边缘留下短反光；纸张哑光且能见细纤维，刷毛柔软、漆木桌面有顺纹磨痕。整体限定灰青、暖纸白与少量棕色。无画内文字或水印。”

这只是原创构图示范；具体服饰、色板、场景和留白方向要按当前作品改写，不把“修复师”当古风题材的必选人物，也未生成图片验证效果。
