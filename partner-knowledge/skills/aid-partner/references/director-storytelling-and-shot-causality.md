# 导演视觉叙事：让每个镜头继承并改变故事

用于完整剧本、两个以上叙事镜头、分镜设计、剧本影像化，以及“单镜很好看但镜头之间断线”的修订。它位于故事契约之后、逐秒视听与提示词之前。目标不是增加镜头术语，而是让摄影、场面调度、剪辑和声音共同表现一条持续变化的故事线。

## 1. 摄影连续不等于故事连续

一镜到底、同一地点、相同人物、统一色调或顺滑转场只能证明形式连续，不能证明剧情连续。若摄影机依次经过若干人物，每人展示一次动作或说一句观点，但前一人的行动没有改变后一人的选择，这仍是并列展示。

进入分镜前，先用普通语言写出全片因果脊柱：

```text
主角此刻想改变什么
→ 为什么现在必须行动
→ 谁或什么真正阻止
→ 主角先采用什么策略
→ 该策略造成什么结果与代价
→ 新状态迫使主角怎样换策略
→ 最终选择是什么
→ 选择让人物、关系或世界变成什么
```

不能用“然后”串起主要段落。相邻段落应能由“因此”或“但是”连接；若只能说“同时又看见另一个人”，它通常是题材陈列、人物画廊或气氛蒙太奇，不是故事推进。蒙太奇可以成立，但要明确承担压缩过程、比较状态、累积证据或制造意义碰撞，不能把并列素材误报为完整剧情。

## 2. 先锁剧情拍，再决定镜头

剧情拍是人物目标或处境发生变化的最小单位，不等于一个镜头。一个剧情拍可以由数镜共同完成，一个长镜头也可以包含多个剧情拍。

每个主要剧情拍先写成：

```text
先前条件
→ 人物行动或有意拒绝行动
→ 对手、关系、规则或现实作出反应
→ 即时结果
→ 信息 / 权力 / 关系 / 风险 / 资源 / 时间 / 物理位置中的实际变化
→ 这项变化强迫、允许或阻断的下一步
```

若删除这一拍，后续人物仍会以同样理由做同样的事，它没有承载因果。可以删掉、并入相邻拍，或让它真正改变后续选项。

配角的出现也服从这条规则。新人物不能只带来一条金句、一个造型或一种社会观察；他必须阻挡、诱导、误导、帮助、见证、索取或改变主角的筹码。否则他属于独立小品，不属于当前故事线。

## 3. 镜头状态卡：每镜必须有进有出

剧情拍通过后，才为实际镜头建立内部状态卡：

```text
镜号与时长：
进入状态：人物位置、目标、知识、关系、持物、环境压力、上一镜未完动作/声音
本镜叙事任务：观众在本镜结束前必须新知道、误判、感受或等待什么
人物行动：谁为了什么，具体作用于谁或什么
阻力与反应：谁如何抵抗、误解、让步或反制
可见状态变化：信息、权力、关系、情绪方向、道具归属、位置、出口或风险改变了什么
退出状态：本镜最后一刻已经成立的画面、动作、视线、声音和未完成压力
下一镜触发：下一镜为什么必须现在出现，它继承了哪项结果
```

镜头可以留下悬念，但不能原样退出。建立空间、情绪消化、气氛和余波镜也要改变观众对距离、缺席、时间、危险或结果的理解。

## 4. 为镜头指定唯一的主要叙事功能

一个镜头可以兼任数项工作，但要有一个主要任务，避免所有镜头都变成“好看的综合展示”。常见任务包括：

- **建立**：让观众读懂后续行动所必需的空间、规则和位置。
- **关系**：在同一构图中显示谁靠近、控制、依赖、回避或被排除。
- **压力**：让阻碍、倒计时、见证者、距离或代价变得更紧。
- **行动**：人物实施会改变条件的策略，而不是一般性走路或摆姿势。
- **线索/揭示**：给出会改变判断或行动的新事实。
- **反应**：展示人物如何理解刚发生的事，并因此改变下一步；同义表情不算。
- **选择/转向**：让旧策略失效，人物作出不可撤回的决定。
- **后果/余波**：让观众看清选择留下的损失、新秩序或未解决压力。
- **过渡**：用时间、空间、声音、动作或意义接力进入新的状态；纯装饰转场不算。

每镜完成后问：观众现在能理解或感受到什么，是镜头开始时不能理解或感受到的？答不出来就不选择运镜，先修剧情任务。

## 5. 场面调度是欲望和权力的几何图

人物站在哪里不是美术摆放，而是目标关系。为每场先画一句空间图：谁占据出口、光源、中心、制高点或关键道具；主角要向哪里移动；阻力从哪里进入；退路在哪里。

调度至少回答：

- 人物正靠近谁或什么，想取得什么？
- 他正避开什么，为什么不能直接离开？
- 谁挡住路线、视线、出口或交流对象？
- 谁主动让出或夺取空间，权力因此怎样改变？
- 身体距离、朝向、高低、遮挡和持物怎样显露潜台词？

人物位置改变必须来自决定、阻拦、失败、让步或新信息；不要让角色为了构图自行换位。重要选择应留下新的空间事实，例如离开队列要跨出队列轴线，而不是沿队尾方向退回；夺回主动要取得门口、中心或关键道具，而不只是换成低角度拍摄。

## 6. 摄影机只响应故事变化

摄影机不是独立表演者。每次启动、停止、改变方向、推近、拉远、环绕、升降、摇移、拉焦或变焦，都要绑定一个已经发生或正在形成的变化：

- 人物作出决定，摄影机随其方向重新组织空间；
- 新事实进入，摄影机把观众视线交给证据；
- 权力转移，构图从一方控制转向另一方控制；
- 压力收紧，观看距离或可见退路发生改变；
- 人物察觉，焦点从其动作转交到所见之物；
- 结果落地，摄影机急停、后撤或保持不动，让观众读清后果。

每次运镜写清：起位与当前构图 → 触发它的动作/信息 → 物理路径与速度曲线 → 经过的前景、人物或遮挡 → 制动时刻 → 最终落点及观众新获得的信息。若故事没有变化，固定机位通常比无理由漂移更诚实。

## 7. 切镜发生在观众理解改变之处

不要因为一句台词说完、时间表要求换景别或“需要节奏”而切。优先保护：

1. 当前情绪和人物选择；
2. 故事信息与因果；
3. 当前段落的节奏；
4. 观众视线的接收位置；
5. 画面方向与二维构图；
6. 三维空间连续。

一个有效切点通常发生在：动作尚在进行且下一角度能完成它；视线提出问题而下一镜给出答案；声音先行带出下一空间；新事实要求改变观看距离；决定已经成立，需要看见受影响者或后果。

景别变化必须增加信息或改变关系。全景、中景、特写依次覆盖同一动作，而没有新的理解，只是重复拍摄。反应镜只在它显示新的知情状态、策略、关系或决定时保留。

## 8. 镜间接力既要连续，也要有因果

为每对相邻镜头记录两层接力：

### 故事接力

- 上一镜的哪项行动或发现迫使下一镜出现？
- 哪项状态已经改变，不能在下一镜复位？
- 下一镜是在确认、复杂化、反制还是兑现上一镜？

### 视听接力

- 动作：未完成动作跨切完成，或同方向动作继续。
- 视线：人物看向画外，下一镜接到所见或故意延迟答案。
- 声音：下一镜声音先进入，或上一镜声音延续到后果画面。
- 方向：人物与摄影机的运动方向保持或有意义地反转。
- 构图/形状/颜色：相似关系连接不同空间，或对比关系制造意义。
- 焦点/遮挡/光线：前一镜隐藏的信息在后一镜被释放。
- 道具：同一物件的归属、损坏、位置或意义继续变化。

视听顺滑不能代替故事接力。动作匹配、声桥和漂亮转场只负责让观众通过接缝；下一镜为什么值得存在仍由人物行动和状态变化回答。

## 9. 用环境、道具和声音讲故事，而不是装饰故事

环境、道具、光线与声音只有在作用于人物选择或观众信息时才承担叙事：

- 门关闭不仅制造氛围，还切断退路或迫使人物换策略；
- 主光源改变不仅改色，还暴露秘密、重排权力或让某人失去隐藏处；
- 重复声音不仅形成风格，还变成倒计时、证据、打断或回调；
- 道具再次出现时改变主人、用途、意义或可选行动，而不是仅证明它还在。

内在变化应寻找外部载体：人物让出位置、收回手、跨过边界、停止回应旧称呼、把物件交给别人、主动进入此前回避的光区。不要用一句主题台词替代已经可以被行为证明的成长。

## 10. 完整剧本和分镜的强制门禁

在输出“完整剧本”、分镜表或开始提示词前，按顺序检查：

1. **普通语言复述**：不提镜头和风格，能否说清主角怎样行动并造成结局？
2. **主角因果权**：如果主角不行动，主要事件和结尾是否仍会发生？若会，故事失败。
3. **相邻因果**：主要段落能否用“因此/但是”连接，而非“然后/同时”？
4. **状态继承**：每场、每镜退出时改变的事实，下一场、下一镜是否真实继承？
5. **删除测试**：删掉某场或某镜，后续选择是否仍同样成立？若是，删除或重建。
6. **配角压力**：每个重要配角是否改变主角的选项、代价、信息或关系？
7. **镜头任务**：每镜是否有主要叙事功能及明确的新理解？
8. **运镜动机**：每次摄影机变化是否由动作、信息、权力或情绪转向触发，并有落点？
9. **空间可读**：人物、阻力、出口、方向、道具和视线是否能跨镜重建？
10. **结尾归因**：结局是否由主角此前的选择生长出来，而不是旁人解释主题并给出答案？
11. **时长容量**：对白、移动、察觉、决定和反应是否按真实表演时间核算，未用快剪压缩本应存在的因果？
12. **无声检查**：暂时去掉解释性对白，关键行动、关系和转向是否仍然可见？

任一上游项失败，退回故事或剧情拍，不能用更多景别、运镜、微表情、BPM、环境细节或提示词长度补救。只有门禁通过后，才进入全片逐秒视听、BPM曲线、动态分镜和模型提示词。

## 11. AID Partner 中的保存方式

- 在项目 `story` 中先保存普通语言因果脊柱、主要剧情拍、场景进入/退出状态和镜间故事接力。
- `shots` 的每个镜头保留唯一ID、剧情决定的时长、完整局部提示词、逐字对白和真实素材引用。
- 镜头提示词的开头应继承上一镜已成立的可见状态；结尾写出下一镜真正能接住的身体、空间、道具、光线、声音和摄影机状态。
- 模型看不到内部故事表；会影响生成的调度、揭示时机、动作、反应、运镜和声音必须进入实际 `prompt`。
- 多个生成段落不等于多个独立小故事。任务边界服从模型容量，镜头和剧情边界服从人物行动与观众理解。

## 研究与原创改写说明

本指南结合了公开导演与剪辑理论中关于“导演概念统一形式、演员可执行行动、剪辑优先服务情绪与故事、相邻画面共同制造意义”的通用方法，并对以下公开 Agent Skill 的故事状态、剧情拍、镜头功能与摄影机动机设计进行了结构研究：`62656456/ai-film-skills` 的 director-agent、`cajias/agentic-video-skills` 的 cinematic-director、`smixs/visual-skills` 的 video dramaturgy，以及 `hoodini/ai-agents-skills` 的 director。这里只保留适合 AID Partner 工作流的决策规律，全部重新组织和原创表述；不加载这些外部 Skill，不复制其人物、案例、固定时长模板或平台参数。
