# H3 8Turbo 与可选视觉风格

2026-09-08，源码阶段记录；用户随后授权发布，0.1.209 发布结果见 `docs/release-0.1.209.md`。用户看过《花少之——我是大姐》对照样片后选择保留复杂提示词，要求 H3 改用 8Turbo，并将七种参考图风格做成页面选项。

## 当前实现

- 保留原有详细 H3 创作提示词结构、对白、人物、动作和音色传递，没有启用精简提示词策略。
- ComfyUI H3 单图、多参考、首尾帧、接续和 Director 路径统一使用 `DasiwaMinimaxH3_dasiwaHybrid8turboV1.safetensors`，8 步、shift video/audio 为 12/3，不叠加四步加速 LoRA。旧浏览器设置和旧任务配置在新提交时归一到 `dasiwa8`，已经提交的任务不会改变。
- 普通 T8 使用 `dual_clock_euler/simple`；Director 使用 `euler/simple`，配套云端兼容补丁允许 4/8 步。移除旧 LoRA 节点并重接模型链，保留参考图、参考音频与 seed。
- Story、连续剧新建/已有项目、角色设计提供电影胶片、iPhone 拍摄、综艺节目、CG 动画（国漫）、3D Q版卡通、纪录片、商业广告。旧风格在“更多风格”中保留。
- 风格会实际进入图片生成请求：拍摄视角、光线、成像和动画造型分别约束；保留剧本地点、时间、人物身份与动作。iPhone、综艺等选择相应拍摄方式。
- Story 切换后立即保存，刷新不丢选择。连续剧支持不上传参考图、仅保存风格；更换时归档旧视觉素材，保留剧本、声音及历史成片。

## 验证

- 11 个测试文件共 120 项通过，覆盖真实图片请求载荷、详细提示词结构、8Turbo 图编译、旧配置迁移、无 LoRA 模型链及风格归档。
- 生产构建、TypeScript 和 diff 空白检查通过。
- 隔离浏览器验证 Story 保存/刷新、拍摄方式联动、七种连续剧选项、无参考图保存/刷新、新建及角色设计选项；没有页面异常。API 使用模拟数据，无生产项目修改或新的付费生成。
- 浏览器回执与截图：`out/verification/h3-8turbo-styles/`。此前已完成两段实际 8Turbo 单镜测试，保存在 `outputs/dasiwa-realism-lab-20260908/`；本次没有重复生成，也没有添加画面质检。
