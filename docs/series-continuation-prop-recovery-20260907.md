# 补镜后的局部校验恢复

状态：源码修复、验证完成，尚未发布或更新运行中的 Companion。

旧流程把“补齐全部镜头”和“通过内容校验”视为一次操作。补镜成功但道具绑定未通过时，只留下失败标记；重试被一次性补镜限制挡住，未使用已经保存的完整回复。

现流程先保存拼接后的完整稿，恢复状态进入 `validating`，然后沿用定点道具/台词修复流程。一次性标记继续限制补镜请求，不限制后续局部修稿。旧失败缓存中的回复会先与原稿完整前缀拼接并验证连续编号及前缀不变，成功后直接进入同一流程。局部修稿网络失败仍保留完整稿；未知结构错误停止，不退回整篇生成。

明确的供应商拒绝、补镜仍不完整、改动已保留前缀、提交结果未知等仍不会重复提交补镜。原始输入、补镜回复、完整候选及恢复状态分别保留。
