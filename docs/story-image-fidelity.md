# Story 与连续剧原图保真提示词

2026-09-09，应用户要求加强原图保留，减少人物、服装、道具和场景无因变形。原图是可见外观与开场空间的首要依据；保留面部比例、皮肤与发型、衣饰纹样、道具形状与材质、光线色温及场景布局。泛化“电影感”不应重新打光、换色或重绘人物。

规则允许剧本明确的表情、口型、动作、运镜、入画出画和物体状态变化，以及相应透视、遮挡和衣料变化，不将保真误写成画面冻结；不虚构未识别的原图颜色或物品细节，不增加视觉识别或质检请求。

规则放在 H3 主视觉描述段的开头，保持原有段落顺序。Story/连续剧共用生成器覆盖 API 路线；ComfyUI 与 fal 的最终提交也补齐规则，因此保存的导演稿覆盖不会绕过增强。重复应用只保留一份规则，逐字对白不参与替换，复杂导演稿保留。独立图生视频入口不变，不自动重生已完成片段。

验证：53项H3提示词/导演稿测试通过，含旧稿覆盖、幂等、对白原样保留、基础及音色参考模式和密集提示词7000字符上限；TypeScript通过。证据outputs/story-image-fidelity-20260909。尚未进行付费生成或画面效果验证，尚未发布网站/更新Companion。
