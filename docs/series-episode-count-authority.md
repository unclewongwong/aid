# 连续剧集数以界面设置为准

2026-09-07，已随0.1.202发布网站并更新本机Companion。

用户确认：上传的裴慎之/白玉杯故事正文没有集数。五十二岁、二十年、两百年前、五贯/八百贯/一千二百贯都是故事事实，不能成为集数。此前“把镜头编号当集数”是根据错误生成范围的推断，不是用户原文包含这些集号。

## 修复

- `createSeries` 的 episodeCount 只来自界面输入，识别到导演成稿也不再覆盖为1。设为1集时继续保留成稿原镜头合同；多集按界面设定走分集编排。
- 总纲提示明确集号与镜号、价格、年龄等无关，JSON示例的结束集/回收集由设定动态生成，单集不再收到固定1–3示例。
- 单集原稿在解析时归一化：全部阶段按原顺序合并到1–1，保留目标和转折文字；所有伏笔的埋设/回收均为第1集，问题、答案、结局不变。原始草稿保留，不额外付费修集号。
- 多集保留已有有效阶段安排；无效区间仍校验，但明确反馈配置集数、实际范围和预期起点，防止笼统修稿。
- 提示词更新后仍按旧提示词精确定位原项目/模型/设置对应缓存，复制到新缓存再续用；旧稿不覆盖，新缓存优先。其他阶段提示词与缓存编号保持不变。

这次与Seedance Mini纯网站API改动不同：连续剧总纲由网页请求本机Companion的 `/api/series/generate`。实际修复需要网站更新及Companion后端更新；单独部署网站不会替换安装包内的校验/提示词/草稿恢复逻辑。
